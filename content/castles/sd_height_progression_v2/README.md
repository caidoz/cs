# 층수와 성장 높이 수정안

이전 sd_final_series_v1은 단계별 건물 높이가 비슷해 성장 표현에 실패한 원화다. 최종 성장 형태로 사용하지 않는다.

본 비교판은 공통 지면과 유사한 바퀴/출입문 축척에서 1~10번의 건물 높이가 순서대로 증가하도록 수정했다. 1번은 낮은 목재 1층 성이며, 단계마다 방 1개 층의 용적을 추가해 마지막 성은 10층 규모로 계획한다. 각 이미지를 같은 높이에 맞춰 전시하는 방식은 사용하지 않는다.

외부 패널을 내부 층마다 반복하지 않고 큰 건축 덩어리, 연결된 기둥, 후퇴한 상층과 돌출 탑으로 조형한다. 실내 상세와 정확한 층별 치수는 아직 설계 전이며 그림이 실제 배치 도면을 대체하지 않는다.

내장 imagegen 사용. same-scale-lineup.png는 수정된 전체 성장 외관 비교안이다. 이전 개별 원화는 이번 높이 차이를 반영한 최종 개별 자산으로 오인하지 않도록 별도로 보관한다. prompt.txt에 생성 지시를 기록했다.
