# SD 성 통합 원화 10종

주의: 단계별 높이가 비슷한 문제로 성장 원화로는 폐기한 버전이다. 수정 성장 비교 기준은 ../sd_height_progression_v2/same-scale-lineup.png를 참조한다. 이 폴더는 작업 이력으로 보관한다.

승인한 마지막 성 v4를 공통 채색/조형 및 전투 데크 배치 기준으로 사용한다. 10번은 승인 원화를 그대로 수록하고, 1~9번은 개별 생성한다. 내장 imagegen 사용. 각 생성 프롬프트는 prompt-NN.txt에 기록한다.

모든 성 공통: 캐릭터 없는 외관, 전체 폭 동료 데크, 우측 히어로 발판, 그 위 별도 지지대의 단일 주포, 축소한 바퀴. SD 비례, 선명한 색과 부드러운 음영, 적절한 단순화. 내부는 나중에 설계하며 방 수가 외부 반복 패널 수를 강제하지 않는다.

| 번호 | 주요 재질 | 상징 | 주포 |
|---|---|---|---|
| 01 | 목재 | 왕관 | 투석기 |
| 02 | 사암/목재 | 멧돼지 | 화염방사 |
| 03 | 화강암 | 교차 검 | 다연장 로켓 |
| 04 | 현무암/구리 | 거북 방패 | 개틀링 |
| 05 | 철/황동 | 사자 | 유도미사일 |
| 06 | 알루미늄/실버 | 기어 | 거대 포탄 |
| 07 | 검은 대리석 | 불사조 | 빙결포 |
| 08 | 백대리석/실버 | 독수리 | 레이저 |
| 09 | 크리스탈/암색 실버 | 눈 | 전격 |
| 10 | 아이보리/골드 | 태양 | 중력 |

파일은 castle-NN.png. 파츠 분할 및 게임 리소스 교체 전의 통합 원화다. 정확한 내부 치수, 캐릭터 배치와 출입 동선은 별도 적용 단계에서 검증한다.
