# 1번 성 기본형 / 풀업그레이드 정측면

내장 image_gen으로 생성한 투명 PNG입니다.

| 파일 | 크기 | 용도 |
| --- | --- | --- |
| body_basic.png | 1672 × 941 | 기존 기본 본체 |
| wheel_basic.png | 1254 × 1254 | 기본 바퀴 |
| body_full.png | 1671 × 941 | 장갑·공성포·망루·농장 풀강화 본체 |
| wheel_full.png | 1254 × 1254 | 철제 보강 바퀴 |

preview.html을 열면 기본형과 강화형을 같은 축·속도로 비교할 수 있습니다.
속도 조절, 역회전, 일시정지, 축 표시, 밝은 배경을 지원합니다.

## 배치

manifest.json은 좌상단 원점의 실제 픽셀 좌표입니다.
scene.contentOffset을 먼저 적용하고 각 body의 x/y/scale로 본체를 그립니다.
두 바퀴는 공통 축 (476, 776), (1227, 776)에 놓습니다.
바퀴 원본 중심 (627, 627)을 원점으로 옮긴 후 wheel.scale과 회전을 적용합니다.
강화 이미지는 생성 과정에서 외곽/축이 달라져 본체별 보정값과 바퀴 배율이 필요합니다.
이 보정값을 적용하면 두 버전의 축과 접지선이 일치합니다.
바퀴 표시 반지름은 185px, 회전량(rad)은 이동거리/185입니다.
본체를 먼저, 바퀴를 앞 레이어에 그립니다.

## 범위

5가지 업그레이드의 기본/풀강화 외형 비교입니다.
현재 본체의 장갑·대포·첨탑·내부는 한 이미지이며 바퀴만 독립 회전 리소스입니다.
각 파츠 5단계 중간 이미지나 독립 교체 레이어는 이 패키지에 포함되지 않습니다.
기존 게임 런타임 리소스는 교체하지 않았습니다.
prompts.json에 생성 프롬프트가 있습니다.
