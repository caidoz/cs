# 둥근 중앙 성채 성장 시안

최신 건축 다양화 시안은 [architectural_progression_v4](../architectural_progression_v4/README.md)다. 이 폴더는 중간 외관 검토안으로 보관한다.

1~10단계의 높이는 계속 증가하며, 최대 높이는 사용자가 지정한 기존 6번째 성의 게임 표시 높이를 기준으로 약 760 단위로 계획했다. 같은 축척에서 폭 증가량은 높이 증가량의 15%다. 단계별 수치는 `layout-spec.json`에 기록한다.

중앙 원통형 성채가 둥글게 돌출된 사이드뷰, 소재와 문양 유지, 단일 우측 포, 동료 발판과 별도 히어로 발판을 사용한다. 마지막 성의 방 수는 10개다.

`progression-board.png`는 전체 외형 비교안, `castle-07-rounded.png`는 꺾인 외형을 수정한 7번째 성의 단독 원화다. 이미지는 내장 imagegen으로 생성했으며 전체 지시는 `prompts.json`에 저장했다. 생성 비교안의 픽셀 치수는 배치 도면이 아니므로 정확한 게임 배치는 별도 수치로 검증해야 한다.

완성 외관 검토용 원화이며 기존 게임 리소스와 파츠 분할은 이번 시안으로 교체하지 않았다.
