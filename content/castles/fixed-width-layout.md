# 성 표시 크기 — 현재 적용 정책

Debug SD 성 1~10단계의 로비·전투 표시는 같은 화면 폭을 사용한다. 폭은 화면의 55%이며, 높이는 각 조립 원화의 종횡비에 비례해 위로 증가한다. 화면 높이에 맞추는 전체 축소와 기존 조립 높이에 따른 추가 축소를 적용하지 않는다.

640px 화면에서 모든 단계의 조립 폭은 352px이다. 높이는 순서대로 약 235, 352, 431, 528, 704, 776, 605, 464, 830, 834px이다. 6~10단계는 [균일 배율 등록](uniform-registration.md)으로 수정해 본체의 세로 늘림을 제거했다. 원본별 높이 차이를 유지하며, 단계별 높이가 반드시 증가하는 디자인은 별도로 원화를 조정해야 한다. 바퀴 접지선은 기존 레일에 유지한다. 화면을 넘는 성은 로비의 세로 드래그로 위층까지 확인할 수 있다. 상세 팝업의 미리보기 배치는 별도 영역 맞춤을 유지한다.

각 성의 이전 제작 기록에 있는 상단 안전영역·가용 높이에 맞춘 축소 설명은 이 정책으로 대체한다. 원화·파츠·리소스 이름은 변경하지 않는다.

검증: `tools/castles/verify_fixed_width.ps1`. 10개 단계의 폭 일치·높이 증가·접지 및 마지막 성 상층까지 카메라 이동을 확인한다. 결과는 `output/fixed-width-review/sizes.csv`와 화면 캡처에 저장한다.
