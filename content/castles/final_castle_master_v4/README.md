# 마지막 성 통합 원화 v4

사용자가 승인한 v3 구조를 기반으로 캐릭터를 모두 제거한 통합 외관 원화다. 파츠 분할 및 게임 리소스 교체는 아직 진행하지 않는다.

유지할 구조:
- 성 옆면 전체 폭의 동료 전투 데크.
- 같은 바닥 높이에서 오른쪽으로 돌출된 히어로 전용 발판.
- 위쪽 별도 받침의 우측을 향한 중력포 한 기.
- 축소한 바퀴 두 개와 차대.
- 태양 문양, 청색 지붕, 아이보리와 금장 외장.
- 방 10개를 위한 내부 용적. 외부 패널은 내부 층마다 반복하지 않는다. 내부는 추후 설계한다.

채색은 클래시 로얄을 참고한 선명한 청색/크림/골드와 단순하고 부드러운 입체 음영이다. SD 비례를 강화하고 작은 리벳·보석·가는 장식·미세 첨탑을 줄인다. 주요 덩어리와 계단형 실루엣, 돌출/후퇴한 벽면으로 입체감을 표현한다.

내장 imagegen 사용. 입력: content/castles/sd_lineup_v3/castle10-full-width-deck.png. 최종 생성 프롬프트: prompt.txt. 통합 원화: assembled-master.png.
