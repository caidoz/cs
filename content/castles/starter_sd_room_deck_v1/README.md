# SD 목조 성 내부와 동료 전투 발판

승인된 SD 목조 성을 기준으로 외부/내부/전투 발판 리소스를 제작했다.
기본 제공 imagegen을 사용했고 프롬프트는 `prompt.txt`에 보관한다.

- 아틀라스: `Resources/res/castle_exterior/starter_sd_room_deck_v1.png`
- 프레임 좌표: `Classes/Data/SdRoomDeck.h`
- 적용 범위: 디버그 빌드의 첫 번째 성, 모든 외장 파츠가 미업그레이드인 경우
- 기존 성의 화면 크기와 지면 기준은 유지한다.

평소에는 보라색 문양이 있는 외벽을 표시한다. 방 근처를 길게 누르면
반경 128픽셀(640픽셀 화면 기준) 안에서 병영 내부와 대기 동료를 보여 준다.
손을 떼면 외벽이 다시 덮인다. 내부에는 무기 선반, 창문, 보급 상자와
빈 보행 공간이 있으며 오른쪽의 출입 통로가 지휘대 쪽으로 이어진다.

주인공과 포탑은 위쪽 지휘대에, 소환된 동료는 그 아래의 긴 전투 발판에
표시한다. 내부 표시에서는 출전 동료를 제외하며, 실제 전투 개체 좌표도
공통 발판 기준점을 사용한다. 발판은 최대 여섯 자리를 화면 안에 확보한다.
현재 샘플의 내부 대표 동료 표시는 최대 여덟 명이며 보유 데이터는 바꾸지 않는다.

검증: `tools/castles/verify_sd_room_deck.ps1`

외벽 기본/터치/해제, 여섯 명 출전, 출전 후 내부 모습의 다섯 화면을
`output/sd-room-deck-review/`에 저장하고, 중복 표시 수와 전투 좌표를 확인한다.

이 리소스는 닫힌 외관/열린 내부/발판 상태를 게임에 연결한 시제품이다.
개별 업그레이드 파츠 전체를 이 시제품 이미지로 대체하는 단계는 아니다.
