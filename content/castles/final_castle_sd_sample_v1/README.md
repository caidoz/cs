# 마지막 10단계 성 SD 샘플

기획의 10층 왕국·황실 테마를 SD 3D 질감으로 검토하는 합산 시안이다.
첫 목조 성의 부드러운 재질·명암 방향을 유지하되, 마지막 성은 아이보리
석재·금장·보라색 왕실 문양으로 구분한다. 포탑은 현행 중력포 테마다.

하단 오른쪽 위에는 중력포와 주인공의 지휘대를 두고, 그 아래에는
최대 여섯 동료가 설 수 있는 개방형 전투 발판을 별도로 연결한다.
내부 단면은 층별 방과 세로 이동 동선, 아래층에서 발판으로 나오는 출입구를 보여 준다.

기본 제공 imagegen으로 외관 합산 시안을 먼저 만든 뒤, 같은 외관을
기준으로 내부 단면을 제작한다. 파츠 분할·게임 리소스 교체 전의 샘플링 단계다.
