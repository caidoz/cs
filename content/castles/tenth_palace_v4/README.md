# 10번째 성 — 왕궁 단독 원화

마지막 건축 다양화 비교안의 10번째 성을 단독 원화로 구체화한다. 아이보리·금색 왕궁, 파란 어니언 돔, 태양 문양과 둥글게 돌출된 중앙 성채를 유지하며 좌우 보조 건축은 비대칭으로 구성한다.

마지막 성은 방 10개를 수용하며, 목표 외곽 크기는 기준 화면에서 높이 760·폭 431이다. 실제 원화의 비율을 유지하며 사용하는 전제이며 가로·세로를 따로 늘리지 않는다. 높이는 사용자가 지정한 기존 6번째 성의 최대 표시 높이를 기준으로 잡았다.

동료용 발판은 하단 전면에 이어지고, 우측 히어로 발판과 같은 높이로 연결된다. 중력포는 우측 히어로 발판 위의 별도 선반에 하나만 배치한다. 인물은 포함하지 않는다.

내장 imagegen 사용. 최초 지시는 [prompt.txt](prompt.txt), 비율 보정까지 포함한 전체 지시는 [prompts.json](prompts.json), 목표 사양은 [design.json](design.json)에 저장한다. 완성 외관 검토용이며 기존 게임 파츠를 아직 교체하지 않았다.
