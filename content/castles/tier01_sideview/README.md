# 1번 성 기본형 — 정측면 리소스

- body.png: 1672 × 941, 투명 PNG. 바퀴가 없는 고정 본체.
- wheel.png: 1254 × 1254, 투명 PNG. 정면 원형 바퀴 1개를 두 축에 재사용.
- preview.html: 브라우저에서 열어 회전·역회전·일시정지·축 표시 확인.
- manifest.json: 실제 크기, 바퀴 축, 회전 중심, 배율, 그리기 순서.
- prompts.json: 내장 image_gen 생성 프롬프트.

## 조합

좌상단 원점의 1672 × 1080 좌표계에서 본체를 (0, 0)에 원본 크기로 그립니다.
바퀴는 원본 기준 (627, 627)을 회전 중심으로 삼고 0.3274336283배로 표시합니다.
바퀴 중심을 (476, 776), (1227, 776)에 배치하고 본체보다 앞에 그립니다.
표시 반지름은 약 185px이며 접지선은 y=961입니다.
모든 요소를 동일 비율로 축소하면 됩니다. 파일 자체의 크기를 변경하지 않아도 됩니다.

회전량(rad) = 이동거리 / 표시 반지름.
화면 좌표에서 오른쪽 이동은 시계 방향, 왼쪽 이동은 반시계 방향입니다.
Cocos2d의 아래쪽 원점 좌표계를 쓸 때 조립 높이 1080 기준 y를 1080-y로 변환합니다.
바퀴 anchor는 (0.5, 0.5)입니다. 본체를 좌상단에 배치하려면 anchor (0, 1)을 사용합니다.

이 패키지는 첫 성 기본형의 본체와 회전 바퀴 리소스입니다.
장갑·대포·첨탑·내부는 현재 본체에 포함되어 있습니다.
기존 게임 성 파일 교체나 런타임 연결은 포함하지 않습니다.
