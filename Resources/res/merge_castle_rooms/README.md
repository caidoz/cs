# 독립 생산시설 리소스

성이 아니라 **시설 한 방의 강화 상태**가 교체 단위다.

- `castle-01.png`~`castle-10.png`: 성별 로딩용 아틀라스.
- 가로 5열 = 식량 / 장비 제작·연구 / 식음료 / 도서·문화 / 성별 특화 생산.
- 세로 6행 = 기본 Lv.0, 강화 Lv.1~5. 총 300개 독립 프레임.
- 행·열의 실제 픽셀 경계는 정수 나눗셈으로 산출한다. 끝 픽셀을 버리지 않는다.
- 런타임은 `MergeCastleTransition::RoomFrame(room, level, width, height)`로 해당 방 하나만 선택한다.
- `robin.castleProgress.rooms[castle][room]`의 기존 저장값을 사용한다. 세이브 필드 추가 없음.
- 성 외곽, 연결 프레임, 메뉴, NPC, 무장, 바퀴, 전투판은 방 이미지 밖에서 따로 그린다.
- 공통 연결 프레임은 기본 단계의 소재를 재사용하므로 개별 방 강화 시 바뀌지 않는다.
- 최종 생성 출처와 프롬프트는 `generation-final.json`. `generation.json`은 보정 전 생성 기록이다.

이미지를 통째로 한 장 그려서 성 실내로 사용하지 않는다. 성 관리의 시설 카드와 로비 모두 같은 독립 프레임을 사용한다.

`approved-structure.png`는 승인된 1단계 시안의 원본 640×850 리소스다. 통째로 배경으로 그리지 않고 기둥·천장·층 바닥 등 지정한 구조 부분만 잘라 공통 프레임으로 사용한다. 각 방 아틀라스의 바깥 테두리는 제거해 중복 프레임을 피한다. 다른 성의 기둥과 바닥은 각 성의 기본 단계 소재에서 가져오며 개별 시설 강화와 독립적이다.
