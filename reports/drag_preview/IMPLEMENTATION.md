# 드래그 설명 구현

2026-10-26. 설계 문서의 실제 적용 기록이다.

## 사용자 동작

- 창고·가방·상점에서 물건을 끌면 이름, 성급, 점유 크기, 기본 기능과 비용을 표시한다.
- 배치 전후를 비교하여 새 연계는 `+`, 해제는 `-`, 유지/상한은 `=`로 표시한다.
  대상 테두리와 점선은 원래 자리의 피해 대상과 새 자리의 이득 대상을 함께 가리킨다.
- 셀 겹침, 성의 잠긴/없는 칸, 가방 범위, 총 점유 한도, 보급력, 골드를 검사한다.
  무효 후보는 실제 연계 수치로 합산하지 않는다.
- 같은 셀에서 잠시 머물면 추가 설명을 펼친다. 긴 설명은 쪽을 나누며 머무는 동안 순환한다.
- 창고 물건을 짧게 누르면 상세가 열린다. 미획득/다른 히어로/다른 성 포대도 제한 사유를
  읽을 수 있으며 상세에는 다음 쪽과 닫기 버튼이 있다. 일반 드래그는 계속 배치 동작이다.
- 가방 물건의 짧은 탭 회전은 유지한다. 회전된 점유 모양과 드롭 판정·그림·설명이 일치한다.
- 상점의 같은 종류·번호·등급 물건 자동 강화, 보관함 이동, 판매, 취소를 실제 해제 경로에 맞춰 구분한다.
- 보유 수량, 골드, 전투 시계, 공격·회복을 실행하지 않고 후보 그래프만 평가한다.

## 효과 범위

- 15종의 225개 방향 조합. 효과 없는 쌍에는 인접 보너스를 새로 만들지 않는다.
- 동료 64종의 원본 프로필, 192개 히어로 연계, 배치/전투 조건, 독립 행동,
  격려, 보급 상한, 동일 ID 시계 공유, 감전-방전/취약-지정 강타의 원거리 연계.
- 포획 몬스터는 기본 공격과 일반 인접 효과만 설명하고 64종 동료의 고유 능력을 부여하지 않는다.
- 투구-검/작전서, 장갑-추가 검, 로키-추가 검, 동료-추가 검, 갑옷 주변 방어구,
  신발-방어막, 바지-해당 동료, 포대 주변 검·정수·포격 동료·방어구.
- 왕/듀라크-작전서는 거리 무관 조건으로 구별한다.
- 일반 스테이지 전용 효과를 PVP의 활성 효과로 합산하지 않는다.

## 전투 판정 정리

- 인접은 `DragPreviewModel.h`의 점유 셀 8방향 규칙을 UI와 전투에서 공유한다.
- 포대의 집계와 설명은 같은 평가기를 사용한다. 추가 타격을 실제 발사 횟수에도 연결했다.
- 바지 인접 효과는 해당 동료의 첫 배치만 찾는다. 다른 동료까지 효과가 번지지 않는다.
- 방어막 발생 목록과 갑옷 주변 방어구 집계를 세 히어로 계열에 적용했다.
- 방어막 쿨타임 함수에 타입 대신 번호를 넘기던 부분을 수정했다.
- 장착 검의 투구 인접 가속도 실제 기본 공격 시계에 반영한다.
- 장갑/로키/협공의 추가 검 전용 경로를 장착 검의 독립 보너스로 표시하지 않는다.
- 반지·목걸이 등의 기본 분류가 무기로 흘러가지 않는다.
- 듀라크 궁극기의 무기·동료 시계는 0 대기 상태 대신 실제 준비 완료 값으로 설정한다.
- 실제 전투 효과가 확인되지 않았던 최하단 신발 `추진` 배지를 제거했다.
- 로라의 구 지원 수리 분기는 새 64종 고유 능력과 중복 적용하지 않는다.
- 정수의 기존 실제 상태 부여는 화염=독, 빙결=둔화, 번개=기절이다.
  신규 동료 상태이상(화상/냉기/감전)과 다르므로 실제 동작을 설명한다.

## 파일

- `Classes/Func_Draw.cpp`, `Func_Input.cpp`: 실제 드래그·탭 연결과 전투 판정 수정
- `Classes/Func_Battle.cpp`, `CastleArtilleryModel.h`, `CastleArtilleryRuntime.inc`: 전투와 동기화
