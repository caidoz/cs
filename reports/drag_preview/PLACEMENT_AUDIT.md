# 배치 설명·포대 연계 점검

2026-10-28 기준. 기획 데이터 `content/hero_allies_balance.tsv`, 생성 데이터
`Classes/Data/AllyBalanceData.h`, 역할표 `Func_Draw.cpp::GetCrewRole`,
설명 `DragPreviewRuntime.inc`, 실제 포대 집계 `StageCannonQuerySynergy`를 대조했다.

|대상|데이터와 실제 규칙|설명 처리|
|---|---|---|
|촌장 뭉크 ID 3|지휘형. 기본 사격 4.2초·85%. 고유 능력 10초·전열 조건·인접 동료 다음 탄 +12%p, 합계 40%p 상한|포대 직접 강화 없음 명시|
|반어인 롤란 ID 8 등 포격형|포대 인접 시 준비 시간 -20%, 탄 크기 +15%, 추가탄 +1|같은 수치 명시|
|용병단장 잭 ID 57|포격형의 추가탄은 +2|예외 수치 명시|

포대 미리보기와 실제 전투는 `DragPreview::CannonEffects`를 공통으로 사용한다.
준비 시간 감소는 합계 60% 상한이다. 동료의 고유 능력 및 히어로 연계는
포격형의 인접 포대 보너스와 별개다. 역할과 행동 능력을 서로 바꾸지 않았다.

배치가 유효하면 위치·인접 조건 변화만 표시하며, 값과 제공자 수가 모두 같은
행은 표시하지 않는다. 배치가 불가능하면 예상 효과를 적용하지 않고 기존
확정 배치를 유지한다. 후보 칸과 설명창을 붉게 표시하고 기본 능력 설명은
회색으로 표시한다. 기본 능력 수치와 순서는 이동 위치로 바뀌지 않는다.

검증: `tools/crew/test_drag_preview.cpp`에 지휘형의 포대 보너스 0,
포격형의 준비 -20%·크기 +15%·추가탄 +1 대조 검증을 추가했다.
