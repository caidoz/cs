# 드래그 정보 표시 시안 v1

2026-10-26. 이번 결과물은 UI·문구·판정 규격이며 게임 동작을 변경하지 않는다.
빈 파일인 `BACKPACK_SYSTEM_DESIGN.md` 대신 실제 코드와 64종 밸런스 원본을 조사했다.
현재 구현과 아래의 권장 수정은 구분한다. 예시 숫자는 실제 아이템의 계산 결과로 교체한다.

## 화면 구성

드래그한 물건보다 위쪽, 손가락에 가리지 않는 곳에 폭 300~340px 설명 카드를 둔다.
640px 화면 기준이며 카드가 화면 밖으로 나가면 반대편으로 옮긴다. 가방·드롭 위치는 가리지 않는다.
상점에서는 가격/보유 금액, 창고에서는 보유/사용 제한, 가방에서는 이동 전후 변화가 우선이다.

```text
┌ 대장장이 로키  ★4     2×2  보급력 4 ┐
│ 기본 사격  4.8초마다 / 공격력 기준 … │
│ 고유 능력  수리: 최대 체력 5% / 8초  │
│ 로빈 연계  명중 시 보호막 +3% / 8초  │
├ 이 자리에 놓으면 ──────────────────┤
│ + 검 A  담금질: 공격력 100 → 125     │
│ − 검 B  담금질: 공격력 125 → 100     │
│ ◇ 전투 중 체력이 부족하면 수리       │
└ 배치 가능 · 보급력 3/10 → 7/10 ─────┘
```

숫자 예시는 형식 설명이다. 로키의 실제 공격 간격 등은 동료 상세표에서 읽는다.
기본 효과와 배치 효과는 별도 줄로 표시한다. 능력이 많으면 변화 3줄과 `외 N개`를 보이고,
같은 셀에서 0.6초 멈추면 펼친다. 드래그 종료 후 상세 고정은 탭으로 제공한다.
대상 이름/번호와 얇은 연결선으로 카드의 줄과 가방의 대상을 연결한다.
장비 이미지 위에는 장문을 덮지 않는다. 캐릭터 발밑 역할 텍스트도 되살리지 않는다.

## 표시 언어와 강조

| 상태 | 기호·문구 | 가방 표시 |
|---|---|---|
| 새 효과 | `+ 담금질 켜짐` | 청록 실선, 대상 테두리 1회 점등 |
| 유지 | `= 담금질 유지` | 얇은 회색 선, 기본은 접음 |
| 잃는 효과 | `− 검 A 담금질 해제` | 주황 점선, 기존 자리의 대상까지 연결 |
| 나쁜 조건 성립 | `! 독립 행동 해제` | 주황 경고, 이득보다 위에 표시 |
| 전투 조건 대기 | `◇ 체력 50% 이하일 때` | 점선 배지, 활성 보너스로 계산하지 않음 |
| 배치 불가 | `× 겹친 칸 2개` | 점유 셀만 빨강, 예상 효과에 `놓을 수 없어 적용 안 됨` |
| 연계 없음 | `이 위치의 추가 연계 없음` | 연결선 없음, 기본 기능은 계속 표시 |
| 한도 | `쿨타임 감소 60% 한도 · 추가 효과 없음` | 상한 배지, 중복 줄 합침 |

색만으로 상태를 구별하지 않는다. 카드 최상단은 배치 불가 사유 → 잃는 효과 → 새 효과 순이다.
창고의 다른 히어로 전용 장비는 원래 색상+얼굴 배지를 유지하고 `디아나 선택 시 사용`을 표시한다.
미획득은 `미획득`, 다른 성 포대는 `현재 성에서 사용 불가`다. 이들은 끌기 시작 대신 탭 상세만 연다.

## 판정 계약

1. 이동 전 전체 배치 A와 후보 배치 B를 읽기 전용으로 각각 평가한다.
2. 가방에서 집은 물건은 A의 원래 자리에서 제거한 뒤 B 후보 위치에 한 번만 넣는다.
3. 셀·회전·점유 마스크로 판정한다. 그림의 좌우 돌출, 얼굴 배지, 이펙트는 인접 판정에 쓰지 않는다.
4. 현재 인접은 상하좌우와 대각선 8방향이다. 긴 물건이 여러 셀을 접해도 한 대상은 1회다.
5. 받는 효과뿐 아니라 주는 효과, 그리고 제삼자에게 생기거나 사라지는 효과도 비교한다.
6. 후보가 유효할 때만 예상 합계를 산출한다. 드래그/미리보기는 사격·회복·쿨타임·난수를 실행하지 않는다.
7. 회전하면 같은 프레임에 전후 비교를 다시 계산한다. 2×2 회전도 그림/방향 규칙과 별개로 처리한다.
8. 전열은 점유 사각형 중심이 오른쪽 절반인 조건(`col*2+w>=gridWidth`), 후열은 그 반대다.
9. 스테이지 전용 능력은 PVP 카드에 `일반 스테이지 전용`이라고 표시하며 활성 효과로 합산하지 않는다.
10. 무기 그림 색상에서 화상·냉기 등을 추정하지 않는다. 실제 정의가 있는 효과만 표시한다.

## 직접 아이템 상호작용

아래는 **방향이 있는** 관계다. 검을 로키 쪽으로 옮기든 로키를 검 쪽으로 옮기든 같은 결과여야 한다.
`L`은 가방 안 런 레벨이며 성급·등급과 혼동하지 않는다.

| ID | 제공자 → 수혜자/조건 | 카드 문구와 전후 예시 | 현재 상태 |
|---|---|---|---|
| I01 | 투구 계열 → 검 인접 | `공격 준비 2.00 → 1.70초 (−15%)` | 검 루프에 있음; 총/부메랑까지 확대 표시 금지 |
| I02 | 장갑 계열 → 검 인접 | `추가 검 피해 100 → 120 (+20%)` | 추가 검 발사 경로. 장착 검 경로와 구별 필요 |
| I03 | 로키 → 검 인접 | `담금질: 검 공격력 +25%` | 검 데이터 산출에 있음 |
| I04 | 동료 → 검 인접 | `추가 검 3회 공격마다 협공` | 추가 검 발사 경로. 동료 수만큼 배수 증가 아님 |
| I05 | 방패/투구/각반/바지 → 갑옷 인접 | `방어막 펄스 위력 +15% × 대상 N개` | 현재 특정 로빈 타입만 집계; 타 히어로 계열 검증 필요 |
| I06 | 신발 계열 → 방어막 발생 장비 인접 | `방어막 재충전 20% 단축` | 방어막 목록에 실제 포함된 장비에만 적용 |
| I07 | 투구 계열 → 작전서 인접 | `궁극기 준비 8.0 → 6.4초` | 구현 있음 |
| I08 | 바지 계열 → 동료 인접 | `성 체력 기여 50% → 100%` | 현재 함수가 동료별 대상을 무시하므로 실제 미리보기 도입 전 수정 필요 |
| I09 | 바지 → 기존 지원 수리 인접 | `수리 5% → 8%` | 구 지원 수리 경로. 새 64종 관리 능력에는 일반화 금지 |
| I10 | 신발 → 최하단 배치 | `추진` | 현재 표시만 확인. 수치 효과 확인 전 유효 보너스로 표시 금지 |
| I11 | 검 → 포대 인접 | `포대 추가 피해 +검 공격력×35%×L` | 집계 있음; 최종 발사 소비 경로 확인 필요 |
| I12 | 불 정수 → 포대 인접 | `포탄 크기 +18%×L` | 집계 있음; 크기와 피해를 혼동하지 않음 |
| I13 | 얼음 정수 → 포대 인접 | `포대 쿨타임 감소 +12%×L` | 냉기 상태이상 부여가 아님 |
| I14 | 번개 정수 → 포대 인접 | `추가 타격 +L회` | 감전 상태이상 부여가 아님 |
| I15 | 마력 정수 → 포대 인접 | `포대 쿨타임 감소 +15%×L` | 총 감소 상한 60% |
| I16 | 포격형 동료 → 포대 인접 | `쿨타임 −20%p / 포탄 크기 +15% / 추가 타격 +1` | 동료 ID/NPC 타입 변환 검증 필요 |
| I17 | 잭 → 포대 인접 | I16 + `추가 타격 +1회 더` | 고유 영웅 연계 사격과 별도 효과 |
| I18 | 갑옷/방패/투구/각반 → 포대 인접 | `추가 피해 +가격×12×L / 포탄 크기 +10%` | 특정 타입 집계. 실제 소비/계열 통일 필요 |
| I19 | 왕 → 작전서, 거리 무관 | `충전시간 ×0.75 / 궁극기 400% → 500%` | 승선한 살아 있는 왕 기준 |
| I20 | 듀라크 → 작전서, 거리 무관 | `궁극기 사용 시 무기·동료 준비시간 연동` | 현 구현은 시계를 0으로 만듦. 즉시 발사라고 표시하면 안 됨 |
| I21 | 로라 → 기존 지원 수리, 거리 무관 | `주기 5 → 3초 / 회복 10% / 보호막 +120` | 구 지원 수리 분기 한정, 새 능력과 구별 |
| I22 | 일반 무기끼리 | `서로 인접 보너스 없음` | 검 개수 증가는 독립 공격 수 증가. 인접 때문이 아님 |
| I23 | 총/부메랑 → 포대 또는 다른 장비 | `추가 인접 효과 없음` | 검의 보너스를 유추하지 않음 |
| I24 | 목걸이/반지 등 공용품 → 주변 | 기본 능력만 표시, 추가 선 없음 | 기본 타입 분류가 무기로 흘러갈 수 있어 엄격한 타입 검사 필요 |

포대 I11~I18은 현재 `StageCannonQuerySynergy` 집계와 배지 사용을 확인했다.
전투 적용을 확인하지 못한 수치를 사용자에게 확정 보너스로 표시하지 않는다.
시안에서는 `연계 예정·전투 적용 확인 필요` 상태로 두고 실제 연결 후 활성화한다.

## 64종 동료의 배치 조건: 빠짐없는 분기

개별 64행과 영웅별 192행은 [동료 케이스 표](drag_preview/ALLIES_CASES.md)에 있다.
같은 조건이라도 고유 능력/수치/공격 주기/히어로 연계는 각 원본 행을 사용한다.

| 조건 | 드래그로 판정할 것 | 카드 문구 |
|---|---|---|
| Always | 배치만 유효하면 준비 | `배치 시 사용 가능 · 전투 중 쿨타임에 따라 발동` |
| Front | 오른쪽 절반 | `전열 충족` / `오른쪽 절반에 배치하세요` |
| Back | 왼쪽 절반 | `후열 충족` / `왼쪽 절반에 배치하세요` |
| AdjacentWeapon | 검·총·부메랑과 접촉 | `무기 인접 충족` / `무기와 붙여 배치하세요` |
| AdjacentCrew | 다른 ID 동료와 접촉 | `동료 인접 충족` / `다른 동료와 붙여 배치하세요` |
| Alone | 다른 ID 동료 비인접 | `독립 행동 충족` / `동료와 붙어 고유 조건 해제` |
| LowHp | 전투 중 성 HP ≤50% | `체력 50% 이하일 때 발동 대기` |
| HighHp | 성 HP >50% | `체력 50% 초과 유지 시` |
| LowShield | 보호막 ≤50% | `보호막 50% 이하일 때` |
| EnemyLowHp | 적 HP ≤50% | `적 체력 50% 이하일 때` |
| EnemyHighHp | 적 HP >50% | `적 체력 50% 초과일 때` |
| EnemyDebuffed | 새 상태이상 모델의 적 디버프 | `적에게 상태이상이 있을 때` |
| EnemyClean | 위 모델의 디버프 없음 | `적에게 상태이상이 없을 때` |
| EveryThird | 원본 영웅 공격 이벤트 3회 누적 | `영웅 공격 이벤트 3회 이후 · 능력 쿨타임 별도` |

로키·아밀·잭은 최초 시제품의 전용 경로도 사용한다. 데이터의 조건 필드만 보고
세 캐릭터의 동작을 일반 동료와 동일하게 설명하지 않는다.
맥스: 로키는 비행 중 수리, 아밀은 귀환 완료 회복, 잭은 귀환 시작에 지원 사격이다.

## 동료가 주변에 주는 효과와 전투 연계

| 케이스 | 표시 |
|---|---|
| 격려 동료 → 인접한 다른 동료 | `다음 적중탄 +N%p`; 대상마다 표시, 합계 상한 40%p |
| 격려 동료를 이동해 대상 교체 | 이전 대상 손실, 새 대상 획득을 둘 다 연결 |
| 동료 이동으로 다른 동료의 독립 조건 해제 | 이동 물건 자체 변화가 없어도 상대의 경고를 표시 |
| 동료 이동으로 다른 동료 인접 조건 충족 | 그 상대의 고유 능력 해금도 표시 |
| 동료/무기 이동으로 전열·후열과 인접 조건 동시 변화 | 조건별 줄, 효과별 최종 상태는 하나만 표시 |
| 원거리 전체 보급 | 이웃만 선 연결하지 않음. 영웅/무기 요약 배지, 주기당 합계 30% 제한 |
| 수리·회복·보호막 | 성 상태 패널에 연결; 회복할 것이 없으면 `충전 후 대기` |
| 수호 | 다음 몬스터 기본 공격에만 적용, 최대 25%, 높은 값 우선 |
| 정화 | `해로운 효과가 있으면 하나 제거`; 상시 방어 수치로 더하지 않음 |
| 추가 사격·강타 | 적 방향 미리보기 아이콘, 즉시 전투를 발생시키지 않음 |
| 흡혈 | 적 존재 + 성 체력 부족 조건을 함께 표시 |
| 감전 공급 동료 + 방전 동료 | 인접 무관 상태 연계. 점선으로 `감전 축적 → 소비`; 확정 피해와 준비 조건 구분 |
| 취약 동료 + 150% 이상 강타 동료 | 인접 무관, 지정 강타 25% 증폭, 취약 소비 표시 |
| 출혈 동료 + 영웅 공격 | 원본 공격당 추가 피해. 파생 공격 재귀 발동 없음 |
| 화상/중독 다중 제공 | 각각 상한 5/6중첩과 갱신 표시, 합산 무한 증가 금지 |
| 냉기 다중 제공 | 3중첩/최대 기본 공격 준비 둔화 15%, 반복 지속 저항 별도 |
| 같은 ID 동료 여러 개 | 능력/시계는 하나, 최초 복사본 위치 사용. `독립 능력 추가 없음` |
| 사망·미배치 동료 | 활성 효과로 합산하지 않음; 편성 예상과 현재 전투 상태 구별 |
| 로빈 연계 | 실제 검 명중이 발동 조건. 검을 붙였다는 이유로 즉시 활성화하지 않음 |
| 디아나 연계 | 기본 총 사격이 조건 |
| 맥스 연계 | 기본은 귀환 완료; 위 시제품 3종 예외 문구 사용 |

## 중첩·모양·복합 배치의 경계 케이스

| 케이스 | 표시 규칙 |
|---|---|
| 투구/장갑 여러 개가 검에 접촉 | 현재 boolean 판정이므로 각각 1회만 적용. `2개 접촉 · 효과 중복 안 됨` |
| 로키 여러 복사본이 한 검에 접촉 | 담금질 1회. +25%가 +50%로 늘어난다고 표시하지 않음 |
| 갑옷 주변 방어 장비 여러 개 | I05는 대상 물건 수로 합산. 같은 물건이 3셀 접해도 1개 |
| 투구+장갑+로키가 한 검에 접촉 | 준비 시간과 피해를 별도 줄로 표시. 피해는 코드 순서와 정수 버림을 그대로 사용 |
| 격려 제공 동료 여러 명 | 대상 다음 탄 강화 합계와 40%p 한도. 공급자별 기여도는 펼친 상세에서 표시 |
| 공급자를 떼어도 다른 공급자가 남음 | 효과가 완전히 사라진다고 표시하지 않고 `유지, 제공자 2 → 1` |
| 회전으로 한 연계는 사라지고 다른 연계는 생김 | 같은 아이템에 대한 변화도 대상/효과별로 분리 |
| 비직사각형 포대의 빈 마스크 셀 | 빈 셀은 충돌/인접의 실체가 아님. 빈 영역을 채운 것과 외곽 접촉 구분 |
| 무기 둘이 동일한 동료에 접촉 | 각 무기의 판정을 개별 계산. 동료 고유 시계 자체를 2개 생성하지 않음 |
| 가운데 선을 걸친 긴 동료 | 위치 중심 기준; 차지한 셀 중 하나가 전열이라고 전열 판정하지 않음 |
| 독립 행동 동료 옆에 무기만 있음 | 독립 조건 유지. 동료 비인접과 모든 물건 비인접은 다름 |
| 모양 밖으로 큰 동료 그림이 돌출 | 그림끼리 닿아도 시너지 없음. 점유 셀만 기준 |
| 적 없음/적 교체/일시정지 | 배치 연계는 예상 가능, 전투 조건은 대기. 미리보기로 실제 시계를 진행하지 않음 |
| 상태 연계가 기존 상한을 넘음 | 초과분 표시 대신 `현재 상한 · 지속 갱신 여부`를 해당 상태 규칙에 맞춰 표시 |
| 현재 조건은 맞지만 추가 사격 슬롯 부족 | 편성 카드에는 준비 가능, 전투 상세에는 `투사체 대기`로 구별 |

## 기본 기능 카드의 필수 필드

| 종류 | 기본 줄 | 주변 연계가 없을 때 |
|---|---|---|
| 검 | 실제 피해, 공격 준비 시간, 장착/추가 검 구분 | 독립 공격 자체는 유지 |
| 총 | 실제 피해, 기본 사격 간격, 디아나 전용 | 검 인접 보너스를 복사하지 않음 |
| 부메랑 | 실제 피해, 비행·복귀·재준비, 맥스 전용 | 복귀 전 재발사 불가 안내 |
| 갑옷·방패 | 방어막 기여/재충전 효과와 발생 주기 | 최대 보호막과 회복 펄스를 별도 표기 |
| 투구·장갑·바지·신발 | 이 아이템이 실제로 주는 수치별 변화 | 착용 스탯/가방 효과를 혼합하지 않고 실제 가방 경로만 표시 |
| 목걸이·반지 | 실제 적용되는 공용 능력 | 가방 적용 경로가 없다면 `도감용 · 가방 효과 없음` 및 편성 제한을 먼저 정비 |
| 포대 | 현재 성·업그레이드 단계·실제 피해·쿨타임·점유 모양 | 성과 맞는 경우 기본 편성됨 |
| 정수 | 속성별 실제 연계 설명 | `포대와 인접 필요`, 기본 공격한다고 표현하지 않음 |
| 작전서 | 궁극기 효과·충전 시간·실제 활성 여부 | 왕·듀라크 연계는 거리 무관 별도 표시 |
| 동료 | 기본 공격·고유 능력·조건·선택 영웅 연계·점유/비용 | 능력 고유 조건이 있는 경우 대기 사유 표시 |

동료의 세 영웅 연계를 모두 카드에 상시 펼치지 않는다. 선택 영웅의 연계 한 줄을 기본으로,
다른 두 영웅은 상세 펼침에서 얼굴 아이콘과 함께 비교한다. 64종 상세표에는 셋 모두 수록한다.

## 모든 종류 쌍의 완전성

[방향별 조합표](drag_preview/PAIR_MATRIX.csv)는 검/총/부메랑/투구/갑옷/장갑/바지/신발/
방패/목걸이/반지/포대/정수/작전서/동료의 총 15종×15종=225쌍을 명시한다.
관계가 없는 쌍도 `직접 인접 효과 없음`이다.
로키/잭/격려/독립/전열 등 특정 동료 예외는 동료 표와 I01~I24를 함께 펼친다.
조합표는 1대1 목록이며 다대다 배치는 위 A/B 차이 계산으로 커버한다.

## 구현 전 반드시 해결할 불일치

- 바지-동료 함수가 전달된 동료 번호를 무시한다. 현재는 한 동료의 접촉이 전원에게 번질 수 있다.
- 방어막 목록이 로빈 일부 타입만 허용해 조끼·코트 등의 뒤쪽 분기가 실행되지 않을 수 있다.
- 장갑/투구의 화면 배지가 검 전체에 붙지만 실제 장착 검과 추가 검의 실행 경로가 다르다.
- `GetItemGearCategory`의 기본값이 WEAPON이므로 반지·목걸이를 무기로 잘못 판정할 수 있다.
- 포격 동료 판정의 보유 동료 ID/NPC 타입 변환을 통일해야 한다.
- 포대 집계 수치가 실제 발사에 소비되는지 확인해야 한다.
- 듀라크의 쿨타임 0 대입이 즉시 준비가 아닌 대기 초기화일 수 있다. 문구부터 과장하지 않는다.
- 같은 ID 최초 복사본 기준은 이동 순서에 따라 결과가 달라질 수 있다. MVP는 명시, 후속은 중복 배치 금지 검토.

## 구현 순서와 확인 기준

1. 읽기 전용 효과 평가기와 타입/대상 버그부터 수정한다. 전투와 UI가 같은 평가 결과를 사용한다.
2. 기본 카드 + P01~P18 + 신규/소실/대기/불가 표시를 구현한다.
3. 직접 인접 I01~I24와 동료 64종, 3영웅 연계를 연결한다.
4. 동일 대상을 여러 셀이 접함, 대각선, 회전, 자기 자리, 해제, 포대 60% 한도,
   격려 40%p·보급 30%·독립 해제·동일 동료 복사본·모드 차이를 검증한다.
5. 보이는 수치와 실제 전투 수치가 일치해야 활성 문구를 허용한다.

관련 소스: `Classes/Func_Draw.cpp`의 GridTestSwords/Shields, GridItemsAreAdjacent,
StageAllyPlacementFor, StageCannonQuerySynergy 및 `Func_Battle.cpp`의 실시간 전투 루프,
`StageAllyBalanceRuntime.inc`, `content/hero_allies_balance.tsv`.
