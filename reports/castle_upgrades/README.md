# 성 파츠 조립 결과

성 10종의 첨탑·대포·외부장갑·실내·바퀴를 Lv.0~5에 연결한다. 총 300개 단계 상태이며, 새로 제작한 성별 아틀라스 10개와 기존 대포 60개 단계 리소스를 사용한다.

완성된 성의 원본 본체를 기준으로 장갑·창·첨탑의 접합점을 맞춘다. 파츠 레벨을 바꿔도 본체의 폭/높이, 데크, 히어로의 발 위치, 바퀴 축은 움직이지 않는다. 바퀴는 원래 축과 반지름을 사용해 회전하며, 혼합 레벨에서도 동일한 장착 기준을 유지한다.

검증 스크립트 `tools/castles/verify_upgrade_parts.ps1`은 성마다 기본, 전체 Lv.1~5, 각 부위만 Lv.5인 상태 5개, 혼합 레벨 1개를 게임에서 실제 렌더링한다. 총 120개 합성 화면 및 120개 배치 고정 검사를 수행한다. 전체 캡처와 로그는 `output/castle-upgrade-parts-review/`에 생성된다.

`preview.html`은 기본·최대 강화·혼합 강화의 실제 게임 캡처를 비교한다. 파츠 원본만 나열한 시안이 아니다.

리소스 위치: `Resources/res/castle_upgrades_v1/`.
생성 방식: 내장 image_gen. 프롬프트: 같은 폴더의 `prompts.json`.
