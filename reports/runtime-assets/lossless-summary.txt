리소스 무손실 압축 결과 (2026-11-18)

직전 AAB: 568,060,466 bytes
최종 AAB: 420,439,183 bytes (420.4 MB / 401.0 MiB)
추가 감소: 147,621,283 bytes, 약 26.0%

현재 사용하는 PNG 2,343장을 무손실 WebP로 인코딩했다. 원본 마스터는 모두
외부 asset_library에 보존했다. RGBA 픽셀, 투명도, 가로세로 크기를 전부
대조했다. 원본에 알파 채널이 있으면 완전 불투명한 그림도 해당 특성을 유지해
기존 게임의 premultiplied-alpha 패널 블렌딩과 동일하게 표시되도록 했다.
손실 압축, 리사이즈, 기능/콘텐츠 삭제는 이번 단계에 적용하지 않았다.

기존 코드/아틀라스/콘텐츠 업데이트에서 쓰는 .png 경로는 호환 ID로 유지한다.
런타임 파일 내용은 WebP일 수 있으며 Cocos는 파일 매직으로 포맷을 판별한다.
올바른 .webp 확장자의 압축 마스터와 인코딩 기록은 외부 라이브러리에 저장한다.

원본 수정 후 실행:
  python tools/assets/optimize_images.py --apply
  python tools/assets/runtime_assets.py stage

스테이징은 원본/압축본 SHA-256을 확인해 원본만 수정하고 압축 갱신을 빠뜨린
빌드를 차단한다. Android 입력에도 원본 마스터를 등록했다. 콘텐츠 업데이트용
manifest의 크기/FNV 지문도 갱신했다. CDN 업로드는 수행하지 않았다.
