# 적용 밸런스 v1 — 런타임 규칙

사용자가 2026-10-25에 실제 64종의 기획·수치 결정과 게임 적용을 위임한 범위다.
[64종 테이블](BALANCE.md)의 이름은 기존 표시 이름이며, 능력명만 새로 설계했다.
원본 ID·이미지·기존 3단계 스킬 및 보유 수량은 유지한다.

## 적용 범위와 데이터

- 일반 스테이지 실시간 전투에서 고유 능력, 기본 공격 간격·배율, 영웅 연계가 적용된다.
  다른 전투 모드의 기존 스킬 처리는 보존한다. 점유 크기는 공유 그리드 정의로 적용한다.
- 편집 원본은 `content/hero_allies_balance.tsv`다.
  `tools/crew/build_ally_balance.py`가 검증 후 `Data/AllyBalanceData.h`, `balance.json`,
  `BALANCE.md`를 생성한다. 파일별로 서로 다른 수치를 수작업으로 고치지 않는다.
- 공격 간격은 기본 사격 간격, 공격 배율은 기존 동료 공격력에 대한 백분율이다.
  기존 동료의 등급별 성장 공격력은 그대로다. 능력·연계는 각각 별도 쿨타임을 쓴다.
- 기존 역할별 임시 공격속도 배수 및 지원형 전체 공통 수리는 일반 전투에서 새 정의로
  대체한다. 로키·아밀·잭의 첫 검증 구현도 테이블의 해당 3개 행과 같은 수치를 사용한다.
- 로라·왕·듀라크의 기존 작전서/대포 연동 등 기존 스킬의 별도 효과는 유지한다.
  이 효과들은 기본 사격 간격 표와 구별된다.

## 효과 수치의 단위

| 효과 | power의 뜻 | 제한 |
|---|---|---|
| Shield | 성 최대 보호막의 %를 회복 | 한 번에 최대 20%, 최대 보호막을 넘지 않음 |
| Heal / Repair | 성 최대 체력의 %를 회복 | 한 번에 최대 15%, 최대 체력을 넘지 않음 |
| Supply | 무기 기본 쿨타임의 %만큼 준비 진행 | 영웅 공격 1주기당 합산 30%; 쿨타임 상한까지만 진행 |
| Inspire | 인접 동료의 다음 적중탄에 공격 배율 포인트 추가 | 합산 최대 40포인트, 적중탄 1발에서 소비 |
| Fortify | 다음 몬스터 기본 공격 피해 감소 % | 중첩 합산하지 않고 큰 값 사용, 최대 25%, 1회 소비 |
| Cleanse | 성에 걸린 기존 해로운 효과 하나 제거 | 한 번에 하나만 제거, 효과가 없으면 대기 |
| Volley | 기존 동료 일반탄 위력의 %로 추가 사격 | 실제 동료 머리에서 살아 있는 적까지 날아가는 투사체 |
| Strike | 영웅 공격력의 %에 해당하는 파생 타격 | 150% 이상을 지정 강타로 취급하여 취약 소비 가능 |
| Leech | 50% 영웅 공격력 타격 후 성 최대 체력의 power% 회복 | 회복은 최대 10%, 적이 없거나 성 체력이 가득 차면 대기 |
| Burn / Poison / Chill / Shock / Bleed / Expose | 명시된 상태이상 중첩 부여 수 | 아래의 개별 상한 적용 |
| Discharge | 감전 4중첩 기준 영웅 공격력의 power% | 실제 감전 중첩/4에 비례, 중첩을 전부 소비; 감전 없으면 피해 없음 |

Supply는 현재 총에 별도의 탄약 재고를 만들어내지 않는다. 검·총·부메랑의 실제
기본 공격 시계를 앞당긴다. 30% 예산과 기존 공격 모션·번쩜·부메랑 복귀 대기를
함께 적용하므로 지원을 중첩해도 무제한 즉시 발사하지 않는다.

## 영웅 이벤트 및 중복 제한

- 로빈: 실제 검 명중. 장착 검과 가방의 검이 명중한 원본 이벤트를 사용한다.
- 디아나: 기본 총 사격.
- 맥스: 고유 연계는 부메랑이 실제로 돌아온 시점. 잭은 귀환 시작에 사격하며,
  로키는 비행 중에 수리하고 아밀은 귀환 완료에 회복한다.
- 효과별 시계는 전투 진행 중에만 증가한다. 동료가 없거나 죽으면 해당 시계를 비운다.
- 매 원본 공격은 런 ID·공격 ID·이벤트 종류로 구분한다. 동일 이벤트 재처리 및
  파생 타격·추가 사격에서 다시 영웅 연계를 발생시키는 경로를 막는다.
- 런 종료 시 능력 시계, 다음 탄 강화, 보호 토큰, 상태이상, 중복 방지 기록을 비운다.
- 같은 동료 ID의 복사본 여러 개를 배치해도 행위자와 능력 시계는 하나다.
  첫 번째 배치된 복사본을 위치 기준으로 삼으며, 같은 ID 복사본끼리는 다른 동료 인접으로 계산하지 않는다.

## 배치와 발동 조건

- 전열은 **가방 오른쪽 절반**, 후열은 왼쪽 절반이다. 적이 화면 오른쪽에 있는 현재
  스테이지 구조를 따른다. 크기 중심을 기준으로 판정한다.
- 인접은 현재 게임의 셀 인접 규칙을 사용하며 대각선 접촉도 포함한다.
- 무기 인접은 검·총·부메랑, 동료 인접은 다른 동료와의 접촉이다.
- 혼자 배치는 다른 동료와 인접하지 않는 조건이다. 무기와는 붙여도 된다.
- 낮은 체력/보호막은 50% 이하, 높은 체력은 50% 초과다.
- EveryThird는 해당 영웅의 명중/사격/귀환 이벤트 세 번 이후 발동 가능하다.
  고유 능력이 발동하면 누적 횟수를 비운다. 주기 제한도 함께 지킨다.
- 조건이 맞지 않거나 회복할 것이 없으면 시계가 가득 찬 채로 대기한다.
  공간 부족 때문에 기존 아이템을 자동으로 삭제하지 않는다.

## 신규 상태이상

| 상태 | 상한 / 기본 지속 | 실제 효과 |
|---|---|---|
| 화상 | 5중첩 / 4초 | 1초마다 중첩당 영웅 공격력 3%의 파생 피해 |
| 중독 | 6중첩 / 8초 | 1초마다 중첩당 영웅 공격력 2%의 파생 피해, 재부여 시 지속 갱신 |
| 냉기 | 3중첩 / 3초 | 중첩당 몬스터 기본 공격 준비 시계 5% 둔화, 최대 15% |
| 감전 | 4중첩 / 5초 | 축적만으로 피해 없음. 명시된 Discharge 효과가 소비해야 피해 발생 |
| 출혈 | 4중첩 / 6초 | 원본 영웅 명중/사격당 중첩당 공격력 3% 파생 피해, 같은 공격 ID에는 1회 |
| 취약 | 1중첩 / 5초 | 다음 지정 강타(Strike 150% 이상)에 소비하여 그 타격을 25% 강화 |

냉기는 강제 기절을 만들지 않는다. 적마다 반복 냉기 부여 시 지속시간 저항이
10포인트씩 쌓여 최대 60% 감소한다. 새 적과 런 시작에서 초기화한다.
기존 독 면역과 둔화 면역은 신규 중독·냉기에도 적용한다.
상태이상 피해는 기존 피해·방어·사망 처리 경로를 사용한다.
그 피해는 원본 영웅 공격으로 재분류하지 않으므로 출혈·감전 소비가 재귀 발동하지 않는다.
화상·감전 등은 명시된 동료/연계에서만 발생하며 무기 그림의 색으로 추정하지 않는다.

## 검증 및 튜닝 기준

64개 고유 능력 이름, 64개 원본 ID·리소스, 192개 영웅별 연계 정의가 존재한다.
공격 간격은 2.4~5.2초, 배율은 기존 공격력의 75~130%, 능력 주기는 3~16초다.
넓은 2×2 동료는 강한 조건부 효과를 가지며, 1×1은 작은 지원 또는 제한된 공격을 맡는다.
이는 실제 플레이테스트용 적용 v1이며, 처치 시간·체력 손실·점유 칸당 기여도를
관찰해 수치 원본을 조정할 수 있다. 최종 경쟁전 공정성을 검증했다고 주장하지 않는다.
