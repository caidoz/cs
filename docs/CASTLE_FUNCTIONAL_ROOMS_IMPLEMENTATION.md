# 성 생산 시설 / NPC 밀도 / 로비 시험 발사

2026-11-02

1~10번째 성의 실내를 성 소재와 외곽 형태를 유지한 생산 시설로 다시 제작했다.
외부를 닫았을 때는 승인된 v1 이미지를 그대로 사용하고, 열었을 때만 새 실내를 사용한다.
1·2·2·3·3·4·4·5·5·5개의 구역으로 구성한다.

- 초반: 조리, 식량 재배·배급, 대장간, 가죽·의복·장비 공방.
- 중반: 주조·기계 조립, 의무, 항해·연구.
- 후반: 기본 생산을 유지하면서 음악·독서·필사, 귀빈 숙소, 보석·직물·가구, 왕립 공연장 추가.

시설 이름과 생산 유형·기본 생산력은 `Classes/Data/CastleFacilities.h`에 둔다.
기존 `castleProgress.rooms[10][5]` 저장값을 재사용하며, 강화 1단계당 기본 생산력의
25%를 더한다(정수 단위, 최대 Lv.5). 기존 방의 전투·적재 보너스는 유지한다.
성 메뉴 하단에 시설별 현재/다음 생산력과 기존 골드 강화 확인·저장 경로를 연결했다.
생산력 값은 기본 생산 대비 가산 보너스(%)이며 임시 밸런스다.

사용자 확정에 따라 식량·고급 식량은 기존 에너지 자동 회복 속도에, 나머지
공방·의약·연구·문화·럭셔리 시설은 기존 골드 생산량에 연결했다.
출정 중인 보유 성의 실제 저장 레벨만 적용하며 디버그 미리보기는 적용하지 않는다.
골드는 기존 금고 상한·오프라인 시간 한도를 유지하고 시간당 정밀도로 계산한다.
에너지는 기존 회복량·최대치를 유지하고 회복 간격만 단축한다.
생산율이 바뀌는 성 변경·시설 강화 시 이전 생산율로 누적 골드를 한 번 정산하고
새 생산 시계를 시작한다. 에너지의 부분 회복 진행도는 새 회복 간격에 맞춰 보존한다.
새 재화나 저장 필드는 추가하지 않았다. 성 메뉴에서 생산 요약과 수금이 가능하다.

로비 `성 테스트`에서 다음을 확인할 수 있다.

- 외형 파츠와 생산 시설의 강화 단계 미리보기.
- NPC 0→8→16→32명 밀도, 실제 표시 수. 기존 동료 CMF와 대기 모션을 사용하며
  목표 높이는 640px 폭에서 36px, 낮은 구역은 구역 높이의 85%로 제한한다.
  가로 밀도에 따라 캐릭터 자체를 더 줄이지 않는다. 포와 겹치는 위치는 제외한다.
- 대포 시험 발사: 10종 기존 발사 프로파일, 장착 단계 크기, 반동과 표적 명중.
  전투 시뮬레이션과 별도 상태를 사용하며 전투 대상·피해·보상에 접근하지 않는다.
- 패널 접기: NPC와 발사를 유지한 채 성 전체를 관찰. 펼친 뒤 닫으면 이전 성과
  실내 상태를 복원한다. 디버그 강화·NPC는 저장하지 않는다.

검증:

- Win32 Debug 빌드 성공. `proj.win32/Debug.win32/cs.exe` 교체.
- 640×850, 640×1136, 640×1280, 640×1408 네 비율에서 10종 성과 NPC,
  10종 대포 명중, 골드·체력·저장값 격리 검사 통과.
- 모든 34개 시설 Lv.0~5 생산력 증가, 강화 비용·골드 부족·최대 단계 검사 통과.
- 실제 시설 강화 확인 버튼과 중복 확인 시 1회 차감 검사 통과.
- 기존 성 구매·외형 파츠 강화·취소·오래된 확인값·스크롤·복원 검사 통과.
- 기존 실시간 전투 회귀: 검 12회, 동료 8회, 대포 6회, 몬스터 12회 명중 및
  일시정지 시계 검사 통과.
- iOS 빌드는 이 Windows 환경에서 수행하지 않았다.

재화 연결 후 `verify_facility_economy.ps1` 추가 검증:

- 34개 시설의 음식/골드 자원 매핑과 Lv.0→5 실제 생산율 변화.
- 실제 에너지 회복, 최대치 유지, 미래 타임스탬프 보정.
- 실제 골드 수금과 중복 수금 방지.
- 생산율 변경 전 골드 정산과 에너지 부분 진행도 유지.
- 네 화면 비율의 재화 보너스 표시 및 강화 확인·1회 차감.
