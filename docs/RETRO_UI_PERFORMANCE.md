# 레트로 UI / 장비 상세창 성능 수정

2026-11-03

공통 패널·버튼·탭·자원 바·팝업을 평면 색상과 얇은 픽셀 테두리로 변경했다.
기존 공통 함수 이름을 유지하므로 장비·성·상점·설정 및 전투 UI 호출부에 함께
반영된다. 성·배경 아트와 아이템·캐릭터 원본, 슬롯/터치 좌표는 유지한다.
장비 상세창의 장착·합성·잠금 기능도 유지한다.

성능 원인과 수정:

1. `Core.cpp`의 공통 팝업 패스가 `menuDepth==0`일 때만 로비 화면을 제외했다.
   장비 상세창을 열면 LobbyDraw가 장비와 상세창을 그린 다음 공통 패스가 전체를
   다시 그렸다. 상세창을 소유한 로비 섹션은 깊이와 관계없이 중복 패스에서 제외했다.
2. `GetSpriteIndex`가 재사용할 스프라이트마다 전체 풀을 선형 검색했다.
   추가만 되는 풀의 기존 텍스처→슬롯 표를 유지하고 O(1) 조회하도록 변경했다.
   표의 3,000개 캐시 한도를 넘으면 실제 할당 범위만 검색하며 범위 밖 쓰기를 막았다.
3. 매 프레임 재사용 표를 지우던 대규모 memset을 제거했다. 커서만 초기화한다.
   문자열 라벨도 같은 방식으로 재사용하며 ResetLabel에서 표를 다시 초기화한다.
   참조되지 않는 레거시 버퍼/텍스트 표의 프레임별 초기화도 제거했다.
4. 9분할 금속 프레임을 단순 패널로 교체해 드로잉 개수를 줄였다.
5. 실제 X 버튼 검사에서 로비 AVK_CLR 처리가 없던 문제를 발견해, 상세창을 닫으면
   장비 목록으로 돌아오도록 수정했다.

Win32 Debug 640×1408의 같은 네이티브 상세창에서 기존 평균 프레임 간격 약
95ms → 45ms, CPU 프레임 준비 약 56ms → 24ms, 스프라이트 1,891개 → 586개.
프레임 간격은 CPU/GPU/대기 시간을 포함한 관측값이며 GPU 전용 계측이 아니다.
이는 Windows Debug 환경 수치로 iOS 또는 60fps 달성을 의미하지 않는다.

진단은 환경변수로만 활성화된다. `CS_UI_PROFILE_PATH`가 프레임 로그 경로이고,
`CS_METAL_UI_REVIEW`는 이전 금속 프레임 비교, `CS_UI_SLOW_POOL_REVIEW`는 이전
조회 방식 비교용이다. 게임 화면에 진단 항목을 추가하지 않았다.

검증 결과와 캡처: `reports/ui_retro/index.html`, `performance.json`.
장비의 네 화면 비율·가로/세로 스크롤·히어로별 장착/전투력·잠금/해제·X 터치를
검사한다. 현재 상점 기획 검사, 시설 생산·강화, 실시간 전투 회귀도 함께 실행한다.
구형 `verify_pixel_shop.ps1`의 추천 탭 IAP 하단 위치 검사는 현재 상점 탭 구성과
맞지 않아 실패했다. 현재 기획을 검사하는 `verify_shop_spec.ps1`로 별도 검증한다.
