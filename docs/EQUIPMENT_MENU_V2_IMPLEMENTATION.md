# 장비 메뉴 V2 적용

## 기준

요청한 `docs/CASTLE_SURVIVOR_EQUIPMENT_MENU_V2_CODEX.md`는 작업 시점에 저장소와 다운로드 폴더에서 발견되지 않았다. 사용자 메시지의 요구사항을 기준으로 구현했다. 문서 전용 세부 규칙은 원문이 제공되면 추가 대조가 필요하다.

## 화면

- 캐릭터 선택: `TOTALCHAR`를 순회하는 가로 목록. 목록 폭보다 캐릭터 수가 많으면 드래그로 이동하고 목록 밖 그리기와 터치는 차단한다. 캐릭터 추가에는 기존 게임의 캐릭터 데이터·리소스 등록이 필요하며 UI 버튼 수와 스크롤 한계는 자동 계산한다.
- 코스튬 및 장착 슬롯: 상단 미리보기와 실제 `TOTALEQUIP` 8개 슬롯. 640×850에서는 선택 목록과 미리보기에 사용 가능 높이의 절반을 배정한다.
- 요약: 기존 `GetCombatPower`의 전체 `ps` 합계, 무기 공격력과 추가 공격력, 방어력, 체력, 치명타와 치명타 피해. 별도 전투력 공식이나 능력을 만들지 않았다.
- 하단: 8열 정사각 아이콘 목록과 세로 스크롤. 기존 부위 필터·상세·장착·합성·일반 판매·잠금·튜토리얼 안내를 연결한다. 강화 표식, 잠금, 새 아이템, 장착 상태만 작은 표시로 유지한다.
- 동료·능력치·도감 탭은 기존 화면과 기능을 유지한다.

## 데이터 연결 시 발견한 문제

실전 히어로는 `ao[PLAYER]`에 선택한 캐릭터를 로드한다. 배열 인덱스 `curHero`와 실제 전투 오브젝트 자리는 같지 않다. 미리보기와 상세 장착은 실제 PLAYER를 사용하고, 다른 캐릭터의 초상과 장착 표시는 저장된 `robin.charData[캐릭터]`를 사용한다.

기존 SaveGame은 오브젝트 자리 번호로 캐릭터 데이터를 저장해서 다른 히어로를 선택하면 로빈의 저장 장비를 덮을 수 있었다. 실제 캐릭터 타입을 기준으로 저장하고, 같은 캐릭터의 보조 오브젝트나 초기화되지 않은 자리는 덮어쓰지 않도록 수정했다. 저장 구조와 아이템 ID는 변경하지 않았다.

## 검증

`tools/lobby/verify_equipment_v2.ps1`은 640×850, 640×960, 640×1136, 640×1408의 네 비율에서 실행한다. 결과는 `output/equipment-v2-높이/`에 저장한다.

검사 항목: 메뉴 진입, 상세/능력치/도감 화면 캡처, 세로 스크롤 경계, 확장된 캐릭터 수의 가로 스크롤 길이, 캐릭터 선택, 액세서리 필터, 세 히어로 각각 실제 장착 명령 실행 후 장비 ID 및 전투력 증가, 다른 히어로의 저장 장비 유지. 테스트 장착 후 리뷰 프로필과 오브젝트를 복구한다.
