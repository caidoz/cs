# 시안 대비 메뉴 재작업

이전 구현은 공통 색과 일부 기능만 연결했으며, 시안의 무대·진열·비교·배경 구성을 충분히 재현하지 못했다. 이전 기능 테스트 결과를 시각적 구현 완료의 근거로 사용할 수 없다.

이번 변경은 공통 청록/황동 프레임의 명암과 안쪽 테두리, 이름을 포함한 가로 캐릭터 선택, 큰 장비 무대, 등급별 장비 칸, 장비 상세의 실제 장착품 비교, 넓은 시설 이미지, 상점 배경과 제목판, 던전 포털 장면, 설정 전체 배경과 토글을 적용한다. 장비 상세는 기존 장착·잠금 명령과 옵션 데이터를 사용한다. 합성은 기존 목록 기능을 유지한다.

시안에 그려진 가상 상품·캐릭터·생산 버프는 추가하지 않는다. 상품, 동료, 장비, 성, 재화는 실제 게임 리소스와 데이터를 사용한다. 던전은 기존 준비 상태를 유지한다. 튜토리얼은 메뉴 검토 중 임시 중지 상태다.

시각적 비교: `reports/menu_renewal_v1/compare.html`. 네 가지 비율의 실제 스크린샷을 원래 시안 옆에 표시한다. 성 10종의 전체 조립 화면도 함께 기록한다.

기능 검증: `tools/lobby/verify_menu_renewal.ps1`, `tools/lobby/verify_pixel_equipment.ps1`. 기능 테스트와 별도로 실제 화면의 텍스트 잘림, 중복 프레임, 여백, 이미지 비율을 확인한다. iOS 기기 검증은 수행하지 않았다.
