# Castle Survivor 조작 튜토리얼

## 표현

각 단계의 실제 화면을 먼저 0.9초 동안 그대로 보여준 뒤, 0.4초 동안 주변을 서서히 어둡게 한다. 기존 DrawHand 이미지로 실제 조작을 안내한다. 조작 영역을 포함하는 원형 포커스 안쪽은 원래 밝기를 유지하고 원의 경계는 부드럽게 처리한다. 드래그에서는 출발점과 목적지를 함께 밝히고 손가락이 두 지점 사이를 반복 이동한다. 마스크는 단일 화면 셰이더로 그려 중복 음영과 다량의 사각형 렌더링을 피한다.

주제와 현재 행동 설명을 큰 글씨로 표시한다. 한 줄 최대 20글자이며 실제 문자열 폭도 검사한다. 글자는 원형 포커스와 최대한 겹치지 않는 세로 위치에 배치한다. 다음 버튼은 표시하지 않는다.

배치 성공 시 기존 장비 장착 효과음 M_BUTTON을 한 번 재생한다. 취소·실패에는 성공음을 재생하지 않는다. 전투 상점의 구매 성공에도 같은 효과음을 사용하며 기존 효과음 설정을 따른다.

드래그 경로에는 반투명 손가락 잔상 6개를 일정 간격으로 표시한다. 잔상은 약 19~31% 불투명도로 표시하고 현재 움직이는 손가락은 선명하게 유지한다. 잔상과 손가락은 같은 직선 경로를 사용한다. 버튼을 누르는 단일 포커스 단계에서는 잔상을 표시하지 않는다. 화면 관찰 시간에는 잔상도 숨기고 주변이 어두워질 때 함께 나타난다.

## 진행

1. 신규 진행과 Reset 후 게스트 로그인으로 로비에 진입하면 모험 시작 버튼을 가리킨다.
2. 준비 화면에서는 보유 창고 장비와 충돌 없이 배치 가능한 목적지를 밝힌다. 유효한 배치 성공 후 진행한다. 취소와 잘못된 배치는 진행하지 않는다. 빈 공간이 없으면 기존 장비를 집어 다시 놓도록 안내한다.
3. 세팅 완료 버튼을 가리키고 실제 준비 종료를 기다린다.
4. 전투 시작 버튼을 가리킨다. 자동 전투 중에는 마스크를 표시하지 않는다.
5. 상점에서는 잔액으로 구매 가능한 장비와 실제 배치 가능한 목적지를 밝힌다. 골드가 차감된 구매 성공 후 진행한다. 구매 가능한 상품이 없으면 마스크를 표시하지 않는다.
6. 다음 전투 시작 버튼을 가리킨다.
7. 로비로 돌아오면 성 메뉴 버튼을 가리킨다. 실제 성 메뉴 진입으로 안내를 완료한다.

## 저장과 예외

단계는 기존 player_flag kind 8에 저장하고 재접속 시 이어서 진행한다. 기존 진행 계정에는 강제 실행하지 않는다. 로비의 ? 기호로 다시 실행하고 X 기호로 종료한다. 안내는 게임 입력을 막지 않는다. 대상이 아직 그려지지 않은 전환 중에는 손가락과 마스크를 표시하지 않는다. 기존 단계 번호와 Next 이벤트는 저장 호환성과 내부 테스트를 위해 유지하지만 다음 버튼은 표시하지 않는다.

## 검증

실제 게임 실행에서 화면 높이 850, 1069, 1280, 1408 각각의 신규 진행, 저장 후 재접속, 완료 및 재실행을 검사한다. 취소 드래그, 유효 배치, 준비 종료, 전투 시작, 잔액 부족, 실제 유료 구매를 검증한다.
