# 성 메뉴 및 파츠 최종 적용

기준 문서: `CASTLE_SURVIVOR_CASTLE_MENU_FINAL_CODEX_SPEC.md` (다운로드 `castle_menu_spec.md` 원문).
추가 지시: 파츠 5종 모두 강화 외형이 바뀌며, 기존 완성 성의 품질과 매끄러운 합성을 우선한다.

## 데이터 매핑

| 화면 부위 | 기존 parts 인덱스 | 효과 / 가격 | 외형 |
|---|---:|---|---|
| 첨탑 | 0 | Attack / UpgradeCost | 성별 강화 첨탑 |
| 대포 | 3 | Attack, CannonDamageMultiplier, CannonCooldownMultiplier | 기존 성별 대포 6단계 |
| 외부장갑 | 1 | Defense / UpgradeCost | 원래 문양 중심에 맞춘 성별 장갑 |
| 실내 | 2 | Health / UpgradeCost | 성별 외벽 재질에 맞춘 창/실내 인셋 |
| 바퀴 | 4 | All / UpgradeCost | 원래 축·반지름에 맞춘 성별 바퀴 |

최대 레벨은 기존 MaxLevel=5. 가격과 저장 ID, 성 레벨 1~10 및 층/인벤토리 확장 규칙은 유지한다. 기존 rooms 5종 데이터와 효과는 삭제하지 않으며 이 화면에 별도 성장 버튼이나 층 미리보기를 만들지 않는다.

## 화면 및 강화

고정 공통 재화 헤더와 `성` 제목 아래 실제 성 이미지 → 성 정보 → 5개 동일 너비 선택 카드 → 선택 파츠 상세 패널 순서다. 이미지부터 마지막 강화 버튼까지 하나의 세로 스크롤 영역이며 노치와 홈바의 기존 안전 영역 값을 사용한다. 긴 화면에서도 컨테이너는 유지하고 콘텐츠가 들어오면 스크롤 범위가 0이 된다.

선택만으로 골드를 차감하지 않는다. 현재/다음 효과, 실제 가격, 부족 골드, MAX를 표시한다. 강화 확인 창은 예상 성/부위/레벨/가격을 기록하고 확정 시 재검사한다. 확인 토큰을 먼저 소비하므로 중복 확정은 재차 차감하지 않는다. 취소와 오래된 확인 입력도 검사한다. 선택과 스크롤 위치는 강화 후 유지한다.

기존 SaveGame → NetMarkDirty를 사용해 골드와 파츠 진행을 동일한 프로필에 저장 요청한다. 네트워크 실패 시 기존 캐시/재시도, 저장 충돌 시 기존 서버 프로필 재로드 정책을 유지한다. UI는 저장 요청과 오류 상태를 표시하며 서버 저장 성공을 거짓으로 확정하지 않는다.

## 합성 리소스

내장 image_gen으로 성별 투명 아틀라스 10개를 제작했다. 첨탑·장갑·실내·바퀴 각 6프레임과 기존 대포 6단계를 연결해 10×5×6=300개 단계 상태를 제공한다. Lv.0은 기존 원본 성을 그대로 사용한다.

기존 본체를 잘라 새 파츠끼리 재배열하지 않는다. 원본 좌표에 장착하는 파츠 방식으로 지붕, 데크, 바퀴 축, 히어로 발 위치를 보존한다. 성별 팔레트와 문양을 맞췄으며, 외부장갑은 원본 문양 중심을 기준으로 배치해 기존 문양과 이중으로 보이던 위치를 수정했다. 8번째 성의 첨탑은 실제 돔의 장착점을 사용한다. 회전 바퀴는 기존 축과 반지름을 사용한다.

리소스: `Resources/res/castle_upgrades_v1/`.
프롬프트: 해당 폴더의 `prompts.json`.
합성 비교: `reports/castle_upgrades/preview.html`.

## 검증

- 10개 성의 기본/전체 Lv.1~5/부위별 단독 Lv.5/혼합 레벨: 실제 렌더 120조합.
- 각 조합에서 본체 크기와 위치, 데크, 히어로 기준점 및 그로부터 산출되는 바퀴 축의 배치 고정 검사.
- 10개 투명 아틀라스와 240개 프레임의 알파 경계 측정. 생성 이미지 픽셀은 후처리로 변경하지 않는다.
- 네 화면: 640×850(약 1:1.33), 640×1069(약 1:1.67), 640×1280(1:2), 640×1408(1:2.2).
- 실제 버튼 터치, 전체 스크롤 끝, 확인/취소/중복/오래된 입력, 골드 부족/MAX, 방 데이터 보존, 성 골드 구매와 출정 변경.

검증 도구: `tools/castles/measure_upgrade_cosmetics.py`, `verify_upgrade_parts.ps1`, `verify_castle_final.ps1`.
Windows 네이티브 빌드에서 검증했다. 이 환경에서 iOS 네이티브 빌드는 실행하지 않았다.
