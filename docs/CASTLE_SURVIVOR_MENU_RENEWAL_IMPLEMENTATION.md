# 메뉴 리뉴얼 적용 결과

2026-11-07. 기획 기준은 `CASTLE_SURVIVOR_MENU_RENEWAL_V1.md`와 `reports/menu_renewal_v1/images/`다. 생성된 완성 UI 이미지를 화면에 붙이는 방식이 아니라 기존 데이터·그리기·입력 명령에 연결했다.

## 적용

- 공통 메뉴: 얇은 황동/청록 테두리, 부드러운 모서리, 아이보리 텍스트, 초록 선택/행동 버튼. 패널은 풀에서 재사용하는 단일 쿼드로 그리며 기존 섹션 클리핑도 지킨다. 전투 중 인벤토리의 원래 그리드는 유지한다.
- 공용 실내 리소스: 무기고·동료실·상점 배경 3개를 하나의 아틀라스로 로드한다. 원본을 비율 유지해 잘라 쓰고 실제 캐릭터·장비는 기존 리소스를 그린다.
- 로비: 기존 배경·성·선로·등장 캐릭터를 유지한다. 출정 버튼을 넓히고 성 격돌과 나란히 배치한다. 전투력과 실제 보관함 사용량/한도를 표시한다. 선택 하단 메뉴 폭과 던전 아이콘 위 잠금을 유지한다.
- 장비: 가로 캐릭터 선택과 8개 실제 슬롯 유지, 무기고 배경과 실제 코스튬, 6열 아이콘 목록, 고정 하단 합성·판매. 실제 장비와 전투력이 연결된다. 64비트 능력치를 32비트 서식으로 표시하던 부분을 수정하고 공격 요약은 전투에서 읽는 `PS_DMG`를 사용한다.
- 동료: 기존 편성 슬롯·별 한도·보유 동료·상세/편성 명령을 재사용한다. 원본 모션의 캐릭터 높이와 발 기준으로 크기를 맞춘다. 장식 NPC를 전투 동료로 바꾸거나 새 생산 능력을 부여하지 않는다. 기존 별도 동료 튜토리얼 실행 중에는 그 튜토리얼용 기존 화면 경로를 유지한다.
- 능력치: 주요 수치를 2열로 정리하고 속성 저항과 기존 `optionInfo` 추가 능력치를 스크롤로 제공한다. 선택 영웅은 `ao[PLAYER]`를 사용한다. 도감과 장비/동료 상세는 기존 동작을 보존하면서 공통 스킨을 적용한다.
- 성: 파츠/생산 시설 탭 분리, 실제 성 합성 미리보기와 출정 성 선택 유지. 성별 시설 수 1/2/2/3/3/4/4/5/5/5와 실제 효과·골드 비용·MAX·확인/취소/중복 차감 방지·수금을 유지한다. 시설 미리보기를 넓혀 방 테마를 읽기 쉽게 했다. 헤더 아래 전체 스크롤은 유지한다.
- 상점: 로비 도크와 터치 영역을 덮고 화면 끝까지 사용한다. 미설정 무료 보상용 빈 패널을 없애고 실제 종합 상자 4개를 추천 앞부분에 둔다. 가격·구성·확률·보관함·실패 처리는 기존 데이터를 따른다. 미연결 전용 상품과 현금 상품을 임의 활성화하지 않는다.
- 던전: 잠긴 아이콘을 누르면 오류음만 내던 경로를 준비 화면으로 연결했다. 보스 토벌/보급 원정/성채 시련은 준비 중이며 실제 입장이나 보상은 없다. 복귀·다른 하단 메뉴 선택이 가능하고 뒤의 디버그 터치가 가로채지 않는다.
- 설정: 음원·효과음·진동·푸시·언어와 기존 고객지원/약관/개인정보/확률정보 명령을 새 목록에 연결했다. 타이틀 Reset과 로그인 흐름은 바꾸지 않았다.
- 성 격돌: 기존 진행·상대 편성·전투 연출을 유지하고 공통 스킨과 상대 확인 헤더를 적용했다. 시안의 정적 VS 레이아웃으로 기존 전투 절차를 대체하지 않았다.

- `Classes/MenuRenewalEquipment.inc`: 동료 및 전체 능력치 목록.
- `Classes/MenuRenewalDungeon.inc`: 던전 준비 화면과 입력.
- `Classes/MenuRenewalOptions.inc`: 기존 설정 명령을 사용하는 새 설정 화면.
- `Classes/EquipmentMenuV2.inc`, `CastleMenuFinal.inc`, `ShopRuntime.inc`, `Func_Draw.cpp`, `Func_Menu.cpp`: 실제 화면 연결.
- `Resources/res/menu_renewal/rooms-v1.png`: 내장 image_gen으로 생성한 공용 배경. `prompts.json`에 최종 프롬프트와 출처 기록. 생성 원본을 수정하지 않고 런타임에서 영역을 선택한다.

## 검증

`tools/lobby/verify_menu_renewal.ps1`은 640×850, 640×1069, 640×1280, 640×1408에서 독립 리뷰 프로필을 실행한다. 실제 메뉴 터치, 던전 진입/복귀, 영웅별 장착 후 전투력, 캐릭터/목록 스크롤, 전체 능력치 접근, 첫 성과 상위 성의 시설 수, 모든 성·파츠·시설 강화, 골드 부족/MAX/중복 확인, 상점 지급/보관함 부족/중복/비활성 상품/도크 터치 차단, 설정 음원 토글을 검사한다.

장비 상세의 잠금·해제·닫기와 기존 튜토리얼, PVP 배치 검사는 별도 기존 검증 도구로 실행한다. 성·상점 모델 테스트도 실행한다. 검증 산출물은 `output/menu-renewal-*`, 실제 캡처 비교 페이지는 `reports/menu_renewal_v1/runtime/index.html`이다.

검증 결과: 네 비율의 네이티브 메뉴 검사 통과, 실제 캡처 48장 확인. 장비 상세 잠금/해제와 모든 영웅 장착 후 전투력 검사 통과. 튜토리얼 신규/저장 재접속/완료 후 재실행 통과. PVP 성 배치·양측 성 선택·10종 크기 비율 검사 통과. 성 모델 및 상점 카탈로그 모델 테스트 통과. 최종 EXE/PDB 식별자와 새 구현 소스의 SHA256 일치 확인.

회귀 검사 자체도 현재 정책에 맞췄다. 모든 성 보유 상태에서는 무료 성 선택을 확인하고, 골드 강화는 확인 명령의 중복 차감까지 검사한다. 무작위 상자 보상 검사와 고정 지급 검사는 독립 인벤토리 상태를 사용해 무작위 드롭의 수량 상한 때문에 서로 실패하지 않게 했다. 실제 런타임 보상 정책은 바꾸지 않았다.

디버그 실행 파일과 PDB는 `proj.win32/Debug.win32/cs.exe`, `cs.pdb`로 함께 빌드한다. iOS 네이티브 빌드와 실기기 프레임률은 이 Windows 환경에서 검증하지 않았다. 구현은 시안의 배치·톤을 기존 기능에 적용한 것이며, 시안에 그려진 가상 아이템이나 임의 경제 수치를 신규 데이터로 추가하지 않았다.
