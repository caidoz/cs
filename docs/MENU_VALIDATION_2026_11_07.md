# 메뉴 검증 빌드

튜토리얼 안내는 메뉴 검증을 위해 임시 중지한다. 기존 진행도는 변경하지 않으며 `CS_TUTORIAL_REVIEW`가 지정된 격리 검증에서만 동작한다. 손 애니메이션 문제는 이번 변경의 완료 범위에 포함하지 않는다.

성 메뉴는 인접한 성 3개를 직접 선택하는 목록, 게임 배경 위의 실제 조립 성, 출정 선택, 전투 파츠/생산 시설 탭으로 구성한다. 양쪽 화살표로 전체 10개 성에 접근할 수 있다. 생산 시설은 성별 개수와 기존 강화·생산 데이터를 사용한다. 신규 생성 시안에 있는 임의 수치와 오브젝트는 추가하지 않는다.

`tools/lobby/verify_menu_renewal.ps1`은 네 가지 비율에서 기존 메뉴 기능을 확인하고, 각 성 1~10의 메뉴 미리보기를 `output/menu-renewal-높이/castle-NN-overview.png`로 저장한다. 이 검증은 별도 프로세스와 테스트 저장소에서 수행한다.
