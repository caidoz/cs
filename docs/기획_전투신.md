# 전투신 기획서

> 성 위에서 벌어지는 한 판을 **어떻게 보이게 할 것인가**.
> 누가 누구를 때리고 맞는지, 칼이 여럿일 때 몸은 무엇을 하는지,
> 스킬이 캐릭터 애니메이션을 끌고 들어올 때 나머지는 어떻게 되는지.

작성일 2026-11-03 · 대상 빌드 `feature/bag-game`
UI 배치(가방을 어디에 둘지)는 [기획_전투신_인벤토리.md](기획_전투신_인벤토리.md) 에서 따로 다룬다.

## 1. 지금 실제로 어떻게 돌아가는가

### 1-1. 아무도 서로를 기다리지 않는다

전투에 참여하는 것이 넷인데, **넷이 각자 제 시계로 돈다.**

| 주체 | 시계 | 치는 방식 |
| :--- | :--- | :--- |
| 가방의 검 N자루 | `stageSwordCool[slot]` 칸마다 | 공전 자리에서 탄이 날아감 |
| 동료 최대 3명 | `stageCrewCool[i]` 사람마다 | 머리 위에서 총탄 |
| 성의 포 | `StageArtilleryStep` | 포신에서 포탄 |
| 작전서(궁극기) | `stageTacticCool[slot]` | 화면 전체 연출 |

`Func_Battle.cpp` 의 주석이 이 설계를 못 박아 두었다:

> 장착 검도 캐릭터 모션을 기다리지 않는다. 모든 검은 자기 시계가 끝난 순간
> 돌던 자리에서 목표로 날아가며, 도착할 때 피해를 준다.
> **따라서 여러 검의 쿨타임과 연출이 서로를 막지 않는다.**

이 결정 자체는 옳다. 검 넷이 0.8초 쿨인데 휘두름이 0.5초면 큐가 밀려서
**칸의 게이지와 화면이 어긋난다.** 다만 그 대가가 지금 그대로 드러나 있다.

### 1-2. 그래서 히어로가 거의 안 움직인다

```c
// 장착 검이 가방에 없으면(자리가 없어 못 넣었거나 맨손) 예전처럼 제
// 시계로 휘두른다. 안 그러면 히어로가 아무것도 안 해 첫 판을 못 넘긴다.
if (!gearSword && running && foe >= 0) { ... PvpHeroGiveTurn(PLAYER); ... }
```

**가방에 검을 넣는 순간 히어로는 휘두르기를 멈춘다.** 검이 혼자 날아가고
사람은 서 있다. 주석의 "아무것도 안 해" 가 지금은 **정상 경로**다.

### 1-3. 궁극기만 화면을 멈추는데, 사실 아무것도 안 멈춘다

```c
stageHeroUltFrame = 45;          // 화이트 플래시 + 띠 배너 + 제목
effect.shake = 5;
AttackObj(PLAYER, foe);          // 4~5 배 피해 + 1.5 초 기절
```

배너는 뜨지만 **검도 동료도 포도 그 45프레임 동안 계속 쏜다.**
가장 큰 한 방이 잔타에 묻힌다.

### 1-4. 맞는 쪽이 얇다

맞으면 `attackedFrame = ATTACKEDFRAME` 하나가 전부다. 누가 때렸는지,
방어막에서 깎였는지 체력에서 깎였는지가 몸으로 안 나온다.

## 2. 전투신의 세 층

연출을 평평하게 깔면 큰 것이 안 커 보인다. **세 층으로 가른다.**

| 층 | 무엇 | 빈도 | 연출 예산 |
| :---: | :--- | :--- | :--- |
| **잔타** | 검·포·동료의 평타 | 초당 3~8회 | 탄 + 피해 숫자 + 칸 번쩍임. **화면은 안 건드린다** |
| **중타** | 치명타, 3타 협공, 동료 스킬 | 5~10초에 1회 | + 짧은 히트스톱(2~3f), 작은 셰이크, 숫자 1.5배 |
| **한 방** | 작전서 궁극기, 보스 처치 | 20초+에 1회 | + 긴 히트스톱(8~12f), **나머지 정지**, 배너, 화이트 플래시 |

> **잔타에 히트스톱을 걸지 않는다.** 검 여럿이 제 시계로 치는 구조라
> 매 타격에 멈추면 게임이 통째로 끊긴다.

## 3. 칼이 여러 개일 때 — 몸은 무엇을 하는가

이것이 이 기획서의 중심 질문이다. 세 갈래.

### (가) 지금처럼 — 칼만 날고 사람은 선다
* 장점: 쿨타임과 화면이 절대 안 어긋난다. 이미 돌아간다.
* 단점: **사람이 장식이 된다.** 주인공이 팔짱 끼고 서 있고 칼만 일한다.

### (나) 큐에 쌓아 하나씩 휘두른다
* 장점: 사람이 계속 움직인다.
* 단점: **큐가 밀린다.** 칸 게이지는 찼는데 사람은 앞 동작 중 — 코드가 이미
  한 번 버린 길이다.

### (다) 몸은 한 박자, 칼은 제 박자 — **권장**

**휘두름을 "대표 동작" 으로 만든다.** 칼 네 자루가 각자 날아가는 것은 그대로
두되, 그 중 **어느 하나가 나갈 때마다** 히어로가 짧은 휘두름을 한 번 친다.
이미 휘두르는 중이면 **덧쓰지 않고 넘긴다**(큐 없음).

```
칼A 발사 ──┐
칼B 발사 ──┼─→ 히어로 휘두름 1회 (0.25초, 중복 격발 무시)
칼C 발사 ──┘
```

* 쿨타임과 화면은 여전히 안 어긋난다 — 휘두름은 **피해와 무관한 장식**이다.
* 사람이 쉼 없이 움직인다. 칼이 많을수록 더 바빠 보인다 = **가방을 채운 보람**.
* 구현: `stageHeroFlash` 가 이미 그런 짧은 깃발이다(`Max(1, FPS/10)`).
  지금은 맨손 경로에서만 선다. **검이 나갈 때도 세우면 된다.**

**부수 규칙**
1. **칼의 종류가 몸짓을 정한다** — 검이면 베기, 총이면 견착, 부메랑이면 던지기.
   히어로 라인이 곧 무기 종류라(§4-2 CLAUDE.md) 분기는 셋이면 족하다.
2. **공전은 유지한다.** 차는 동안 머리 위를 도는 그림이 "몇 자루 들었나" 를
   말해 준다. 그게 가방의 시각화다.
3. **나가는 칼은 공전에서 빠진다** — 지금도 그렇다. 돌던 자리가 곧 발사점이다.

## 4. 스킬이 캐릭터 애니메이션을 끌고 올 때

동료 스킬과 히어로 궁극기는 **사람이 직접 하는 동작**이다. 이때 나머지(검·포·
다른 동료)를 어떻게 할 것인가.

### (가) 그대로 둔다 — 지금
큰 한 방이 잔타에 묻힌다. 궁극기 배너 뒤로 평타 숫자가 계속 뜬다.

### (나) 전부 멈춘다
깔끔하지만 **쿨타임이 멈추는가**가 문제다. 멈추면 DPS가 연출 길이에 좌우되고,
안 멈추면 끝나는 순간 쌓인 게 한꺼번에 터진다.

### (다) 층에 따라 다르게 — **권장**

| 층 | 나머지 처리 |
| :--- | :--- |
| **동료 스킬 (중타)** | 아무것도 안 멈춘다. 그 동료만 제 모션. 대신 **그 동료를 한 발짝 앞으로** 내보내 누가 하는지 보이게 한다 |
| **3타 협공 (중타)** | 히어로 모션 + 짧은 히트스톱 2~3f. 검은 계속 난다 |
| **궁극기 (한 방)** | **시계는 계속 돌되 발사만 보류**한다. 연출이 끝나는 프레임에 보류분이 차례로 나간다 — 멈춘 느낌 없이 큰 한 방이 혼자 선다 |

> **핵심은 "시계를 멈추지 말고 발사를 미룬다" 이다.**
> 시계를 멈추면 DPS가 연출에 끌려가고, 아무것도 안 하면 큰 것이 묻힌다.
> 발사만 미루면 총량은 그대로이고 화면만 정리된다.

```c
//뼈대 — 보류 창
//  stageHoldFrame > 0 이면 새 발사를 큐에 넣고 내보내지 않는다.
//  0 이 되는 프레임에 큐를 한 자루씩 두세 프레임 간격으로 쏟는다.
#define STAGE_HOLD_ULT      (FPS * 3 / 4)   //궁극기 동안 보류
#define STAGE_HOLD_DRAIN    3               //끝난 뒤 한 발씩 터지는 간격
```

보류분이 쏟아지는 그림은 **덤으로 박진감을 준다** — 궁극기 직후 일제 사격.

## 5. 맞는 쪽

때리는 쪽만 공들이면 "허공에 치는" 싸움이 된다. 맞는 표현에 세 가지를 둔다.

1. **방어막과 체력을 다르게 친다.** 방어막에서 깎이면 **파랑 파문**,
   체력에서 깎이면 **붉은 점멸**. 2단 게이지(§3 CLAUDE.md)가 이미 둘을 나눠
   세고 있으니 화면에서도 갈라야 한다.
2. **마지막 한 겹** — 방어막이 0이 되는 그 타격에 짧은 유리 깨짐. 플레이어가
   "이제부터 진짜 체력" 을 몸으로 안다.
3. **넉백은 주지 않는다.** 히어로는 성 지휘대에 서 있고 적은 레일 위로 온다.
   밀리면 자리가 흐트러져 누가 어디 있는지 읽기 어려워진다. 대신 **제자리
   흔들림**으로 대체한다.

## 6. 적도 같은 규칙으로 움직인다

몬스터도 가방을 메고 있다(`StageGearList` · `FoeGearData.h`). 그러므로
**적의 공격도 §3의 규칙을 그대로 따른다** — 장비가 제 시계로 나가고, 몸은
대표 동작을 한 번 친다.

이게 지켜져야 "적의 가방을 보고 내 가방을 짠다"(입장 직후 출정 준비)가
말이 된다. 적이 무엇을 들었는지가 **화면에서도 같은 방식으로** 드러나야 한다.

## 7. 결정이 필요한 것

1. **대표 휘두름의 길이** — 0.25초 제안. 칼이 여섯이면 거의 쉬지 않게 된다.
   더 짧게(0.15초) 해서 연타감을 줄 것인가?
2. **궁극기 보류 창을 몇 초로 둘 것인가** — 0.75초 제안. 길면 끊긴 느낌,
   짧으면 안 비켜진다.
3. **동료 스킬도 보류 창을 줄 것인가** — 제안은 "아니오"(중타는 안 멈춘다).
   다만 ★5·★6 동료 스킬은 한 방 층으로 올릴 수도 있다.
4. **무기 종류별 몸짓을 지금 넣을 것인가** — 모션표가 히어로마다 다르므로
   (`motionData`) 확인이 필요하다. 1단계는 공용 휘두름 하나로 가고 뒤에 가를
   수도 있다.
5. **적의 대표 동작** — 몬스터 모션표에 공격 동작이 다 있는가. 없는 종류는
   제자리 들썩임으로 대체할 것인가.

## 8. 단계

| 단계 | 할 일 | 효과 |
| :---: | :--- | :--- |
| 1 | 검이 나갈 때 히어로 대표 휘두름 1회 (중복 무시) | 사람이 장식에서 벗어난다 |
| 2 | 연출 3층 분리 — 잔타/중타/한 방의 히트스톱·셰이크 등급표 | 큰 것이 커 보인다 |
| 3 | 궁극기 보류 창 + 끝난 뒤 일제 사격 | 한 방이 혼자 선다 |
| 4 | 맞는 쪽 — 방어막/체력 구분, 마지막 한 겹 | 허공에 치지 않는다 |
| 5 | 적에게 같은 규칙 적용 | 적 가방이 화면에서 읽힌다 |
| 6 | (선택) 무기 종류별 몸짓 | 라인마다 손맛이 갈린다 |
