# 상점 보물상자

장비 탭은 미설정 히어로 상품을 노출하지 않고 실제 구매 가능한 보물상자를 먼저 보여준다. 기존 장비/패키지/재화 탭 구분은 유지한다. 보급 상자·유료 상자 표기는 보물상자로 통일한다.

| 기존 상자 계열 | 구매 재화 | 가격 |
|---|---|---:|
| 브론즈 | 골드 | 100 |
| 실버 | 골드 | 500 |
| 크리스탈 | 보석 (`robin.coin`) | 30 |
| 아케인 | 보석 | 100 |
| 로열 | 보석 | 300 |
| 레전드 | 보석 | 1,000 |

가격은 판 수에 따라 증가하는 전투 보상 평가액과 분리한다. `Config/ShopConfig.h`의 `ShopTreasure` 설정을 카드·확인창·실제 구매가 함께 사용한다. 보석 그림은 상단 재화 바와 같은 무지개 보석이다.

기존 카드 수·장비/동료 추첨 확률을 사용한다. 구매한 상자의 직접 골드 보상 상한은 25/125/300/1,000/3,000/10,000, 에너지 상한은 3/5/8/12/16/20이다. 낮아진 구매 가격으로 큰 전투용 골드·에너지 보상을 반복 수령하지 않도록 한 상점 전용 조정이다. 확인창도 조정된 범위를 표시한다. 전투에서 얻는 상자 보상표는 변경하지 않는다.

부족한 재화·보관함 부족·중복 요청·지급 실패 시 기존 트랜잭션 보호를 유지한다. 격리 네이티브 검증은 상위 네 등급의 보석 차감과 골드 보상 정산을 각각 확인한다. 모든 아이템 재판매·합성 경로를 포함한 경제 전체의 균형 검증을 의미하지는 않는다.
