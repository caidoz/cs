# 성별 기능성 방과 5단계 업그레이드

현재 렌더링과 리소스 등록은 [실내 통합 V4](CASTLE_ROOM_INTEGRATED_V4.md)를 따른다. 아래 V3 타일 합성 설명은 이전 방식이다.

기존 성의 본체·첨탑·외부장갑·대포·바퀴·데크와 방 영역을 유지한다. 실내가 열렸을 때 기존 방 영역에만 새 시설을 합성한다. 방마다 저장된 `castleProgress.rooms[castle][room]`의 0~5를 읽으므로 방 하나의 강화가 다른 방의 외형을 바꾸지 않는다. 새 세이브 필드는 없다.

| 성 | 소재·테마 | 방 수 |
|---|---|---:|
| 1 | 목재 개척 농장 | 1 |
| 2 | 사암 보급 요새 | 2 |
| 3 | 백석 기사단 | 2 |
| 4 | 비취 수산 요새 | 3 |
| 5 | 강철 공업 요새 | 3 |
| 6 | 청록 공학 성 | 4 |
| 7 | 붉은 봉황 성 | 4 |
| 8 | 백조 학술 궁전 | 5 |
| 9 | 수정 마법 성 | 5 |
| 10 | 태양 왕실 궁전 | 5 |

각 성은 생산, 장비 연구, 식음료·공연, 도서·종교, 왕실 특화 순서로 시설을 가진다. 성별 최대 방 수까지만 존재한다. 작물·수조·대장간·기계·책장·제단·연회 설비가 단계별로 발전한다. 색조만 바꾼 외형이 아니다.

10개 아틀라스를 내장 image_gen으로 생성했다. 각 시설은 기본 상태 + 업그레이드 1~5, 총 6개 상태이며 34개 시설에 204개 상태를 사용한다. 경로와 전체 프롬프트는 `Resources/res/castle_room_upgrades_v3/generation.json`, 실제 크롭은 `registration.json`에 있다. 사암 아틀라스의 여분 낙농 행은 사용하지 않고, 대장간의 실제 행을 별도로 등록했다.

런타임은 `SoftCastle::Sectors`의 기존 위치·크기로 그린다. 가구 비율을 유지하며 크롭하고 가장자리를 얇게 혼합한다. NPC는 새 방 아트 위에 기존 픽셀 캐릭터로 그린다. 건물 전체나 방 개수를 다시 조립하지 않는다.

생산 시설은 에너지 회복, 나머지는 기존 골드 생산 보너스를 유지한다. 2번 장비 연구 시설은 강화 시 아군 공격력에도 추가 반영한다. 추가 공격력은 `Output(level) - Output(0)`이며 기본 상태에서 추가 공격력은 0이다. 기존 체력·방어력·적재량·장비 칸 효과와 저장 구조는 유지한다.

로비 성 테스트에서 **생산 시설·단계 보기 → 개별 방 또는 모든 방 단계 +**로 0~5를 순환할 수 있다. 이 테스트는 골드와 실제 강화 저장값을 변경하지 않는다. 실제 강화는 기존 성 메뉴의 골드 확인·차감·저장 경로를 사용한다.

NPC 영역 인수인계는 `docs/CASTLE_NPC_PLACEMENT_HANDOFF.md`와 `Classes/Data/CastleNpcPlacement.h`를 참조한다. 실제 게임 캡처는 `reports/art_direction/room_upgrades.html`에서 성별·단계별로 비교할 수 있다.
