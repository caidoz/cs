# Castle Survivor 메뉴 리뉴얼 기획 V1

작성: 2026-11-07. 이 문서는 최초 메뉴 기획과 이미지 시안의 기준이다. 이후 구현 요청으로 네이티브 메뉴를 개편했으며 실제 적용 범위와 검증은 `CASTLE_SURVIVOR_MENU_RENEWAL_IMPLEMENTATION.md`에 기록했다. 세이브 구조와 경제 밸런스는 유지한다.

## 목표와 공통 방향

현재의 SD 성·계곡·선로와 픽셀 캐릭터 조합을 유지한다. 메뉴는 따뜻한 목재·석재를 배경 소재로 사용하고, 얇은 황동 테두리와 짙은 청록 패널로 통일한다. 두꺼운 금속 베벨, 과도한 광택, 거대한 제목 장식은 사용하지 않는다. 전체 화면 배경 일러스트를 늘리기보다 작은 실내 배경과 실제 콘텐츠를 조합한다.

메뉴의 핵심 작업은 로비의 출정, 장비의 장착·합성, 동료의 편성, 성의 강화·수금, 상점의 구매다. 각 화면에서 주된 행동을 하나씩 두드러지게 한다. 숫자는 기존 계산 결과와 데이터에서 가져온다. 생성 이미지의 숫자·아이콘·상품 구성은 레이아웃 설명용 예시이며 실제 지급이나 밸런스 정의가 아니다.

공통 색상: 잉크 `#152D37`, 청록 `#2F6570`, 황동 `#C5A269`, 아이보리 `#F2E7CB`, 행동 버튼 초록 `#467B55`. 선택은 밝은 테두리+배경 변화로 표시하고 색만으로 상태를 구분하지 않는다. 잠금은 실제 아이콘 위에 자물쇠를 겹친다.

## 화면별 메뉴 기획

### 01 로비 / 모험

상단 공통 재화 → 지역·거리의 작은 안내판 → 실제 성과 선로 → 전투력 요약 → 모험 시작 → 하단 아이콘 순서다. 성은 큰 외형을 유지하고 최종 성도 같은 크기로 축소하지 않는다. 지역 배경과 성의 대비를 조정해 캐릭터가 묻히지 않게 한다.

모험 시작은 기존 에너지 비용을 읽는다. 성 격돌은 보조 행동이다. 캐릭터·성 변경 후 전투력은 실제 계산을 사용하고 기존 숫자 변화 연출을 이어 쓴다. 샘플의 보급력은 표시 위치 예시이며, 로비에 유효한 편성 스냅샷이 없을 때는 성의 적재 정보로 바꾸고 미확정 출정 값을 표시하지 않는다. 디버그는 개발 설정에서만 분리 노출한다.

### 02 장비

헤더 아래 캐릭터 선택은 가로 스크롤이다. 현재 세 명에 고정하지 않는다. 선택한 캐릭터의 실제 코스튬과 장착 아이템을 중앙에, 기존 8개 슬롯은 양옆에 둔다. 미리보기에 창고 아이템을 임의로 장착해 그리지 않는다.

약 1:1.33 화면에서는 캐릭터 선택+미리보기가 콘텐츠 높이의 약 절반이다. 그 아래 전투력·주요 능력치·4개 탭, 보유 장비 그리드가 이어진다. 그리드는 기본 6열, 화면에 따라 6~8열이며 아이콘 비율을 유지한다. 이름·긴 설명·장식 카드는 상세에서만 보여준다. 강화, 장착, 잠금, 신규 표시는 작은 상태 표식으로 남긴다. 필터와 합성·판매는 현재 기능을 연결한다.

상세는 비교 가능한 시트다. 선택 아이템, 현재 장착품, 실제 변화량, 장착/해제, 합성, 잠금을 제공한다. 계산 조건이 같으면 다른 화면에서도 설명과 효과가 같아야 한다. 출정 임시 장비와 영구 보관함은 혼합하지 않는다.

### 03 상점

상단 재화 아래 헤더·3개 탭을 고정하고, 콘텐츠는 화면 맨 아래까지 세로 스크롤한다. 기존 로비 도크는 시각·터치 모두 숨긴다. 제목 위아래에 빈 띠를 두지 않는다.

추천: 실제 구매 가능한 종합 상자 → 전용 보급 구성 미리보기. 무료 보상 미설정 상태는 추천 최상단을 차지하지 않는다. 보급품: 히어로 선택 → 무기/방어구/동료/특수 구성 → 기존 종합 상자. 패키지: 연결 전에는 짧은 빈 상태와 이전 탭 복귀 행동만 제공한다. 구매 복구 상태가 있을 때는 해당 복구 상태를 우선 보여준다.

상품은 실제 이름·가격·드롭 목록을 읽는다. 시안에 그려진 임의 보석·물약·두루마리는 실제 상품으로 추가하지 않는다. 모든 골드는 기존 공통 픽셀 골드 아이콘을 쓴다. 미설정 상품에 무료/할인/한정 배지를 만들지 않는다. 구매 확인에서 실제 가격과 보관함 여유를 확인하고, 실패 시 재화가 차감된 것처럼 연출하지 않는다.

### 04 성

가로 성 목록 → 실제 합성 성 미리보기 → 이름·출정 상태 → 전투 파츠/생산 시설 탭 → 선택 콘텐츠 순서다. 기존 미리보기 함수를 재사용하고 본체·실내·바퀴를 중복해서 그리지 않는다. 선택한 성과 출정 성을 구분하고, 다른 성을 강화해도 자동으로 출정 성을 바꾸지 않는다.

전투 파츠 탭: 첨탑·대포·외부장갑·실내·바퀴 5개 선택 → 현재/다음 효과 → 실제 골드 비용 → 강화 확인. 모든 성의 대포 특성과 기존 외형 단계는 유지한다.

생산 시설 탭: 해당 성의 시설만 표시 → 현재 생산 요약·수금 → 시설 카드 → 선택 시설 Lv.0~5 강화. 카드에는 실제 방 이미지·시설명·생산 자원에 대응한 효과·다음 효과·실제 강화 비용이 필요하다. 서로 다른 성의 시설 수를 고정 빈 슬롯으로 채우지 않는다.

정확한 시설명과효과는 `Classes/Data/CastleFacilities.h`가 기준이다. 총 34개 시설이며 각 시설의 Lv.0~5를 유지한다. 이미지가 제시하는 Lv.0의 +12% → Lv.1의 +15%는 첫 시설의 현재 데이터 예다. 단계별 비용은 시안 문구가 아니라 `UpgradeCost` 및 시설 강화 함수에서 읽는다. 최대 단계에는 다음 효과·비용 대신 MAX를 표시한다.

### 05 던전: 신규 콘텐츠 제안

현재 잠긴 다섯 번째 아이콘을 유지한다. 누르면 오류음만 내는 대신, 포털 장면과 준비 중 콘텐츠를 보여주는 화면을 제안한다. 이번 샘플은 콘텐츠 방향이며 실제 해금·전투·보상을 구현한 화면이 아니다.

| 제안 모드 | 플레이 목적 | 재사용 후보 | 출시 전 결정할 내용 |
|---|---|---|---|
| 보스 토벌 | 단일 보스에 맞춘 편성 시험 | 기존 보스·장비 쿨타임·전투 결과 | 입장 비용, 시간 제한, 보상표, 최초/반복 보상 구분 |
| 보급 원정 | 성 성장용 기존 자원 확보 | 기존 웨이브·골드·에너지 | 모험 대비 효율, 횟수, 재시도·중단 정산 |
| 성채 시련 | 배치 제약을 해결하는 도전 | 기존 그리드·충돌·시너지 판정 | 제약 세트, 진행 저장, 보상, 난이도 곡선 |

이름과 모드는 신규 제안이다. 임의 레벨 해금 조건·입장권·신규 재화·상품을 생성하지 않는다. 연결 전에는 모든 입장 행동을 잠그고 로비 복귀만 활성화한다.

### 06 동료

장비 메뉴의 동료 탭으로 유지한다. 영웅 선택 → 실제 편성 슬롯 → 보유 동료 → 선택 동료의 조건·효과 → 편성/해제 순서다. 슬롯 수는 기존 편성 제한 데이터를 읽고, 시안의 4명은 고정 정원으로 사용하지 않는다.

모든 동료는 원본 프레임의 실제 캐릭터 영역을 기준으로 영웅의 약 절반 크기로 맞추고 발 위치를 일치시킨다. 단순 프레임 최대 폭/높이 비율로 서로 다르게 축소하지 않는다. 실내 장식 NPC와 실제 전투 편성 동료는 별도다. 시안의 공격/지원/생산 분류는 검색 UX 제안이며, 현재 동료 데이터에 없는 생산 버프를 만들지 않는다. 생산 분류를 데이터로 검증할 수 없으면 해당 필터를 숨긴다.

### 07 성 격돌

로비에서 접근하는 별도 모드로 유지한다. 상대 정보 → 양측 성·전투력 비교 → 편성 → 실제 시작 순서다. 현재 테스트/AI 경로와 온라인 대전 서비스를 구분한다. 실제 매칭 서버 확인 전에는 실시간 상대 검색·랭킹·시즌 보상을 표시하지 않는다. 상대를 확인한 뒤 편성을 여는 기존 흐름을 유지한다.

### 08 상세·능력치·도감·설정

장비 상세: 상단 선택품/장착품 비교, 변화량, 하단 장착·합성·잠금. 큰 중첩 프레임을 줄인다. 능력치: 전투력과 기존 실제 능력치를 2열로 표시하고 수치 출처를 펼쳐 볼 수 있게 설계한다. 도감: 기존 보유·미보유·보상 정보를 작은 그리드와 진행률로 정리한다. 설정: 기존 제공되는 음원·효과음·언어·알림·계정/지원 항목을 그룹화하며 연결되지 않은 계정 버튼은 추가하지 않는다.

## 레이아웃과 구현 제약

시안은 생성 도구가 출력한 약 1:1.37 비율의 압축 화면을 중심으로 구성했다. 기기 비율 검증을 완료한 실행 UI가 아니다. 이후 구현에서는 640×850, 640×1069, 640×1280, 640×1408에서 검증한다. 이미지 전체를 화면에 늘려 넣지 않고 패널·텍스트·아이콘을 코드로 재구성한다.

640×850: 장비 상단 약 절반, 목록만 스크롤. 성은 헤더 아래 전체 콘텐츠 스크롤, 층 미리보기 없음. 상점은 헤더·탭 고정, 나머지 전체 화면 스크롤. 긴 화면에서는 목록 가시 행을 늘리고 캐릭터·글자 배율을 무작정 키우지 않는다. 최소 터치 목표는 48 기준 픽셀, 바깥 여백 16~20, 그리드 간격 6~10을 기준으로 실제 기기에서 조정한다.

공통 골드·프리즘·에너지는 기존 아이콘을 재사용한다. 시안의 생성 아이콘을 실제 게임 아이템으로 대체하지 않는다. 캐릭터와 거대 보스는 기존 픽셀 리소스를 유지한다. 배경·성의 이미지 정체성을 생성 시안과 일치시키기 위해 실제 성을 새로 그리거나 리깅을 변경하지 않는다. 상태 변화는 짧은 강조·숫자 변화로 표현하고 전체 화면 이동·불필요한 대기 연출을 넣지 않는다.

## 구현 순서와 수용 기준

1. 공통 패널·버튼·탭·재화·슬롯 상태, 레이아웃 토큰을 먼저 적용한다.
2. 로비/장비/동료: 실제 외형·전투력·선택 캐릭터 저장, 가로/세로 스크롤, 합성·잠금·판매 회귀 검사.
3. 성: 10개 성과 34개 시설, 파츠 5종, Lv.0~5, 비용/MAX/부족/취소/중복 확인, 출정 성 분리, 미리보기 실루엣 검사.
4. 상점: 도크 덮음·터치 차단, 실제 가격/구성, 보관함 초과, 중복 구매 방지, 실패·복구·미연결 상태 검사.
5. 도감/능력치/설정과 성 격돌의 기존 명령을 새 레이아웃에 연결한다.
6. 던전은 준비 화면까지만 먼저 연결하고, 실제 3개 모드는 경제·전투 기획 확정 후 별도 구현한다.

이번 작업은 시안 제작이며 위 구현 작업이나 모바일 빌드 검증을 완료한 것으로 보고하지 않는다. 시안 안의 새 인물·아이템·시설 썸네일은 분위기 참고용이다. 실제 데이터와 다르게 생성된 문구나 아이콘은 그대로 출시하지 않는다.
