# Castle Survivor — 성 메뉴 최종 구현 기획서

버전: FINAL v2.0 / 2026-10-29
상태: UI 구성 및 성장 원칙 확정. 실제 파츠 레벨 상한·효과·가격·리소스 경로는 **현재 프로젝트 데이터가 기준**.
대상: Cocos2d-x C++ / 세로형 모바일

## 1. 확정 원칙
1. 성 메뉴의 순서는 **실제 성열차 이미지 → 성 정보 → 업그레이드 파츠 5종 → 선택 파츠 상세/업그레이드**이다.
2. 5개 파츠는 **첨탑, 대포, 외부장갑, 실내, 바퀴**로 고정한다. 다른 성장 버튼을 추가하지 않는다.
3. **층 미리보기, 성 단면도, 구조·인벤토리·시설·외형 탭을 이 화면에 추가하지 않는다.** 상단 성 이미지가 코스튬 변화의 유일한 미리보기다.
4. 상단 성열차 이미지는 게임에서 실제 사용 중인 **기존 파츠 리소스 및 조립·렌더링 로직**으로 출력한다. 새 콘셉트 이미지나 대체 이미지를 사용하지 않는다.
5. 파츠 업그레이드 성공 시 **해당 파츠 코스튬을 즉시 갱신**한다. 나머지 파츠의 상태는 유지한다.
6. 업그레이드 비용은 **골드만** 사용한다. 건축 재료, 정비 부품, 인벤토리 확장권, 별도 업그레이드 재화를 추가하지 않는다.
7. 기존 성 레벨 1~10, 층 및 인벤토리 공간 자동 확장 규칙을 보존한다. 파츠 레벨과 성 레벨의 관계는 기존 코드에서 확인하고 임의 변경하지 않는다.
8. 성 메뉴에서 성 인벤토리 아이템을 드래그·배치하지 않는다. 해당 기능은 탐험 준비 화면에 둔다.

## 2. 화면 구성 (위에서 아래로 단일 세로 스크롤)
### A. 헤더
- 뒤로가기, `성` 제목, 골드. 다이아 등 기타 재화는 기존 공통 헤더 정책을 따르되 업그레이드 비용에는 사용하지 않는다.
- 헤더는 화면 상단 고정. 기기 안전 영역 및 노치 고려.

### B. 실제 성열차 코스튬
- 현재 소유 성의 **실제 게임 파츠 조합**을 렌더링한다.
- 첨탑/대포/외부장갑/실내/바퀴의 현재 단계가 반영되어야 한다.
- 화면 폭에 맞춰 비율 유지; 잘라내기, 비균일 확대 금지. 배경은 기존 게임 성 화면 리소스를 우선 사용.
- 선택 파츠를 약한 테두리·점멸로 강조할 수 있으나 원본 스프라이트를 훼손하지 않는다.
- 업그레이드 직후 해당 파츠만 갱신할 수 있으면 부분 갱신, 아니면 전체 성 합성 이미지를 재렌더링한다.

### C. 성 정보 요약
- 성 이름, 성 레벨, 현재 층 수, 현재 인벤토리 규모.
- 기존 데이터에 실제로 존재하는 성 능력치만 추가 표시한다. 임의로 HP, 골드 생산량, 전투력 등을 만들어 넣지 않는다.
- 성 레벨업 기능이 별도로 존재한다면 기존 위치/동선을 유지하되, 5개 파츠 버튼을 대체하거나 6번째 파츠로 만들지 않는다.

### D. 5개 파츠 선택 바
- 순서 고정: **첨탑 | 대포 | 외부장갑 | 실내 | 바퀴**.
- 각 카드: 기존 파츠 픽셀 아이콘(가능하면 실제 파츠 이미지), 이름, 현재 Lv, 선택 상태, 강화 가능 표시.
- 동일 너비 5개를 한 줄에 우선 배치. 작은 기기에서 터치 목표가 지나치게 작아지면 **이 선택 바만 가로 스크롤** 허용; 버튼을 읽을 수 없을 정도로 축소하지 않는다.
- 카드 선택 시 아래 상세 패널만 교체한다. 화면 전체 재진입 금지.

### E. 선택 파츠 상세/강화 패널
- 파츠명 / 현재 레벨 / 기존 효과 / 다음 레벨 효과 / 필요한 골드 / 업그레이드 버튼.
- 효과 수치와 파츠 레벨 상한은 기존 데이터에서 읽는다. 데이터가 없으면 임의 숫자를 생성하지 않고 `효과 정보 없음` 또는 `최대 레벨` 등 정확한 상태를 표시한다.
- 골드 부족: 버튼 비활성화 + 부족 골드 안내. 최대 레벨: `MAX` 표시, 결제 불가.
- 업그레이드 확인 후 단일 트랜잭션으로 골드 차감, 파츠 레벨 변경, 저장, UI/코스튬 갱신. 중복 탭·연속 입력으로 이중 차감되지 않도록 방지.
- 업그레이드 성공 후 현재 선택 파츠 및 **현재 스크롤 위치 유지**. 자동 최상단 이동 금지.

## 3. 작은 화면 스크롤 — 필수 구현
- **1:1.33(최우선)**: 고정 헤더를 제외한 **성 이미지부터 상세 강화 패널 끝까지 전체가 하나의 세로 스크롤 컨테이너**에 속한다. 어떤 패널도 화면 하단에서 잘려 접근 불가능해지면 안 된다.
- 성 이미지, 정보, 파츠 버튼, 상세 패널을 화면 높이에 억지로 맞추기 위해 일괄 축소하지 않는다.
- **1:1.67**: 콘텐츠가 가용 높이를 초과하면 같은 세로 스크롤 동작.
- **1:2 / 1:2.2**: 콘텐츠가 들어오면 스크롤이 필요 없을 수 있으나 스크롤 컨테이너는 유지. 남는 공간은 자연스러운 간격으로 처리한다.
- 헤더만 고정; 성 이미지와 성 정보는 **고정하지 않는다**.
- 하단 안전 영역을 고려하여 마지막 업그레이드 버튼 아래 충분한 스크롤 여백을 제공한다.
- 스크롤 위치 보존: 파츠 선택, 업그레이드 성공, 코스튬 재렌더링 시 점프 금지. 메뉴 재진입 시 초기 위치 정책은 기존 UI를 따른다.
- 스크롤 터치와 5개 파츠 버튼 터치를 구분한다. 가로 스크롤 선택 바가 필요한 경우 수직/수평 제스처 충돌 방지.
- 최소 터치 크기와 텍스트 가독성은 기존 공통 UI 규칙을 준수한다.

## 4. 데이터/로직 연결
- 기존 성 데이터와 파츠 레벨 ID를 조사하여 첨탑·대포·외부장갑·실내·바퀴에 1:1 매핑한다.
- 기존 파츠별 단계별 스프라이트/애니메이션/합성 좌표를 그대로 사용한다.
- 기존 골드 잔액, 가격표, 레벨 상한, 효과표, 저장/로드 로직을 재사용한다.
- 기존 성 레벨업으로 층·인벤토리 자동 확장이 발생한다면 이를 유지하며, 파츠 업그레이드가 그 기능을 임의로 호출하지 않도록 한다(기존 코드가 연동되어 있으면 먼저 보고).
- UI에서 사용하는 숫자·상태는 모델 데이터 바인딩. 하드코딩된 가짜 레벨·비용·효과 금지.

## 5. 화면 상태 및 예외 처리
- 기본 선택 파츠: 첨탑(기존 마지막 선택 기억 기능이 있으면 재사용 가능).
- 골드 부족, MAX, 미해금 파츠(기존 정책에 한함), 리소스 로드 실패, 저장 실패 상태를 처리한다.
- 저장 실패 시 골드/레벨/UI가 서로 다른 상태로 남지 않도록 기존 트랜잭션 또는 롤백 정책을 따른다.
- 미구현 기능을 동작하는 버튼처럼 보이게 만들지 않는다.

## 6. 구현 순서 (Codex)
1. 현재 성 메뉴/파츠 데이터/실제 성 렌더러/골드 업그레이드/저장 코드를 조사한다.
2. 기존 5종 파츠와 실제 ID·레벨·코스튬·효과·비용 매핑 표를 작성한다.
3. 헤더 + 단일 세로 스크롤 레이아웃을 구성한다.
4. 실제 게임 성열차 렌더러를 상단에 연결한다.
5. 성 정보 요약, 5개 선택 카드, 선택 파츠 상세 패널을 구현한다.
6. 기존 업그레이드 함수를 연결하고 성공 시 코스튬/정보/골드를 동기화한다.
7. 1:1.33 / 1:1.67 / 1:2 / 1:2.2 화면에서 터치·스크롤·버튼 접근성 검증한다.
8. 변경 파일, 기존 코드 재사용 내역, 미확정 데이터, 테스트 결과를 보고한다.

## 7. 필수 검수 기준
- [ ] 실제 게임 성열차 파츠 이미지가 표시된다(가상 시안 이미지 사용 금지).
- [ ] 성 이미지 바로 아래 성 정보가 나온다.
- [ ] 업그레이드 파츠가 정확히 첨탑/대포/외부장갑/실내/바퀴 5개다.
- [ ] 선택 파츠의 현재/다음 단계와 골드 비용이 기존 데이터와 일치한다.
- [ ] 성공 시 골드 차감, 저장, 해당 파츠 외형 갱신이 즉시 이루어진다.
- [ ] 층 미리보기·성 단면도·불필요한 탭이 없다.
- [ ] 1:1.33에서 마지막 업그레이드 버튼까지 스크롤로 도달 가능하다.
- [ ] 작은 화면에서 텍스트·버튼이 과도하게 축소되지 않는다.
- [ ] 스크롤 위치가 파츠 변경/강화 후 유지된다.
- [ ] 성 레벨업은 골드만 사용하고 층/인벤토리 자동 확장 기존 규칙을 유지한다.
- [ ] 상점/장비/탐험 준비 기능을 침범하지 않는다.

## 8. Codex 실행 프롬프트
`docs/CASTLE_SURVIVOR_CASTLE_MENU_FINAL_CODEX_SPEC.md`를 읽고 기존 성 메뉴를 실제로 수정해 줘. 먼저 프로젝트의 실제 성 파츠 렌더링, 5개 파츠 레벨/가격/효과 데이터, 골드 저장 로직을 확인해. 화면 순서는 실제 성열차 이미지 → 성 정보 → 첨탑·대포·외부장갑·실내·바퀴 5개 선택 → 선택 파츠 상세/골드 업그레이드로 고정한다. 층 미리보기는 만들지 않는다. 1:1.33에서 헤더 아래 전체가 세로 스크롤되며 마지막 강화 버튼까지 접근 가능해야 한다. 기존 코스튬을 즉시 반영하고 스크롤 위치를 유지한다. 기존 기능과 데이터는 임의 변경하지 말고 구현 결과와 테스트를 보고해 줘.
